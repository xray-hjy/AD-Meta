# PRJCA022804 来源论文补充材料

这两份文件是论文 *Metagenomic analysis characterizes stage-specific gut microbiota in Alzheimer's disease* 的补充材料，配合当前 185 个 AD/NC 样本的来源核对使用；它们不是原始测序 reads，也不是本项目的分析流程或分析结果。

- `41380_2025_2973_MOESM1_ESM.docx`：补充说明及论文作者的方法描述。方法仅代表论文作者的分析，不能据此认定本项目采用了相同流程。
- `41380_2025_2973_MOESM2_ESM.xlsx`：补充表格。Table S1 含样本编号、疾病分组、年龄、性别等信息；已核对当前 `samples_current185.tsv` 中 185 个样本均能匹配，分组、年龄和性别一致。

## 使用边界

可用于追溯样本编号及核对公开的疾病/基本受试者信息。样本级匹配不等于受试者匿名 ID 或重复采样关系已确认；Table S3/S4 等论文结果表也不是本项目重新分析得到的矩阵。项目自身物种、KO 等矩阵的生成脚本、参数、软件/数据库版本及数值单位仍须以本项目实际运行记录为准。
