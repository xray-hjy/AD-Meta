# 输入文件归档

按“数据类型 / 来源数据集编号 / 文件”组织，不将不同来源的同类表格混放。

```text
raw/
├─ ad-nc-species/
│  └─ PRJCA022804/          # 物种结果、样本分组和说明
├─ ad-nc-ko-abundance/
│  └─ PRJCA022804/          # KO、配对通路结果和说明
└─ source-supplements/
   └─ PRJCA022804/          # 来源论文补充材料和说明
```

新增其他数据集时，在对应数据类型下面建立其来源编号目录。若没有公开项目编号，可使用明确、稳定的本地数据集标识。文件属于哪个目录不决定导入行为；实际输入路径仍由 `backend/storage_manifest.json` 指定，不自动扫描、合并其他目录。

现有 `raw.csv` 是对应数据集的旧结果，保留但不作为当前导入输入。同一来源以后有新的同名结果时不得覆盖已归档文件，应另建明确的结果版本子目录，再更新导入清单。

`raw` 表示平台接收的输入文件，不表示其中全部都是原始测序 Reads。论文补充材料用于来源核对，不作为本项目分析流程的证明。

2026-10-18 目录整理仅调整文件位置及当前引用；原始表格、补充材料字节不变，未重新导入数据、修改已发布修订或重写历史证据归档。历史记录中的旧路径保留其当时含义，当前文件位置以本目录及导入清单为准。
