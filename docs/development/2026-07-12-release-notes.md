# AD-Meta 2026-07-12 更新日志

## 更新概览

本次更新围绕“前端分析工作区重构”和“分类层级图体系化”展开。项目仍采用后端预计算、前端渲染的前后端分离架构，并将原本围绕单一旭日图组织的分类数据处理，升级为可供多种分类层级可视化复用的统一能力。

## 前端架构

- 新增首页与分析工作区路由，首页作为平台入口，物种丰度与 KO 丰度分析继续集中在分析工作区。
- 将原先集中在 `App.jsx` 的职责拆分为路由、页面、布局、数据访问、图表注册、状态 Hook 和基础 UI 组件。
- 建立统一设计令牌与基础样式，包括颜色、间距、边框、阴影、交互状态和响应式规则。
- 新增数据集选择、数据概览、分析导航、工作区头部等可复用布局组件。
- 引入统一的 `ChartFrame`、`ChartViewport` 和分类层级专用视口策略，使卡片、可视区域和 ECharts 实例共享同一套尺寸约束。
- 保留白色、克制的科研分析界面，并增强导航选中态、按钮反馈、卡片交互和页面过渡。

## 分类层级后端

- 建立正式的 `taxonomy` 分类层级模块，统一负责层级树构建、剪枝、配色与可视化投影。
- 统一分类层级树作为唯一事实数据源，旭日图、矩形树图、桑基图和放射树图不再各自维护一套分类数据。
- 新增 `taxonomy_sankey` 后端预计算结果，直接输出节点、连线和布局元数据，前端优先消费预计算 payload。
- 保留 `sunburst` 和 `taxonomy_tree` 的薄兼容入口，兼容历史缓存和旧导入路径，但不再作为正式架构入口。
- 当前分类树压缩规则保持为 801 个节点、607 个叶节点，并合并 3814 个长尾分支。

## 分类层级可视化

### 旭日图

- 支持门、纲、属、物种层级占比展示及原生下钻动画。
- 小门级在旭日图总览中合并为 `Others`，图例保留各子级真实占比；下钻后展示 `Other phyla`、`Fusobacteria` 和 `Euryarchaeota` 的真实分类结构与对应颜色。
- 沿用 ECharts 原生灰色返回内圈和下钻状态，不额外模拟返回按钮。
- 最外层标签纳入布局空间计算，避免在不同屏幕尺寸下被画布裁切。
- 优化圆形半径、图例布局、标签边距和卡片适配。

### 矩形树图

- 按门级保持一致配色，并通过层级标题呈现当前分类路径。
- 根据色块尺寸动态决定标签显示、截断和横竖排列；窄而高的色块使用单行竖排标签。
- 小色块采用更细的边线，减少白色边界吞噬填充色的问题。
- 视口高度按可用卡片空间和宽高比计算，避免大屏幕下被压扁、笔记本下被裁切。

### 桑基图

- 使用后端预计算的 `taxonomy_sankey` 节点和连线，减少前端重复转换与主线程计算。
- 为桑基图投影增加独立的长尾聚合预算，在保留总丰度的前提下将低丰度同级节点合并为 `Other`，不改变共享分类树。
- 将 Canvas 高度限制为 3040px、设备像素比限制为 1.5，并降低布局迭代、关闭初始动画，避免超大画布占用数百 MB 内存。
- 根据聚合后的节点密度计算画布高度和节点间距，展示主要物种标签并避免重叠。
- 使用独立的多层级桑基配色，不强制复用旭日图色板。
- 画布与卡片可用区域联动；内容超出时保留必要滚动，不在卡片右侧或底部制造无效空白。

### 放射树图

- 使用统一分类层级树与压缩规则，保持节点规模和分类含义一致。
- 恢复 ECharts 放射树节点、连线、标签和后代聚焦交互。
- 按叶节点数量与可用区域计算布局尺寸，并为外层标签预留空间。

## 其他图表与交互

- 统一 AD 为红色、NC 为绿色，并以 KO 丰度对比图使用的颜色为基准。
- 优化门级组成和 KO 功能组成条形图的悬浮强调、条间距、横向布局及末端数值。
- 调整 PCA、PCoA 的等比例尺寸、居中方式、图例和统计说明；PCA 展示 PC1、PC2 及累计解释率，PCoA 保留 PERMANOVA 结果。
- 修复箱线图中位线仅在悬浮时明显的问题，使四分位信息在默认状态下可读。
- 优化 KO 检出率热图居中、LDA 柱状图、差异图和通用图表标题信息，减少重复说明。

## 数据与接口

- 新增前端数据集 API 层与数据获取 Hook，页面不再直接承担请求、缓存和状态拼装。
- 数据集摘要、图表数据和分类层级投影通过明确的服务边界提供。
- 更新预计算流程、数据集服务、配置和相关测试，以支持正式的 `taxonomy` 与 `taxonomy_sankey` 类型。

## 文档

- 新增项目概览、系统架构、文档导航和分类层级可视化开发记录。
- 项目定位明确为面向 AD 脑肠轴研究的肠道宏基因组研发辅助工具；上游生物信息分析流程独立开发，不属于本仓库运行时组成。
- 整理运行手册、API、数据库和开发记录，移除已失真的旧前端代码参考文档。

## 兼容与升级说明

- 前端新增 `react-router-dom`，更新代码后需在 `frontend` 目录重新执行 `npm install`。
- 历史调用仍可通过 `charts.sunburst.compute_sunburst` 使用兼容入口；新增代码应使用正式分类层级模块。
- `COMPUTE_VERSION` 已更新为 `2026-07-12-v1`；更新代码后应按运行手册重新生成本地缓存，以获得聚合后的 `taxonomy_sankey`。
