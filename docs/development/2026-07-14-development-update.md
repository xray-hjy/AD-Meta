## 生物信息分析路线展示

- 首页补充从公共宏基因组测序数据到结构化分析结果的完整技术路线：

```text
公共宏基因组测序数据
  -> Raw FASTQ
  -> 质量控制与序列过滤
  -> 宿主污染去除
  -> Clean Reads
```

- 在共同预处理之后展示三条并行分支：
  - Reads 水平物种分析：`Kraken2 -> Bracken -> Sample x Species`。
  - 群落整体功能分析：`MEGAHIT -> 基因预测 -> 功能注释 -> Reads 定量 -> Sample x KO`。
  - 基因组解析宏基因组：`Coverage -> Binning -> 质量评价 -> 去冗余 -> 分类与功能注释`，最终形成 Final MAGs 及其下游分析结果。
- 完整路线用于说明已确定的研发方向，不代表本仓库能够在线执行 FASTQ 处理、组装、分箱或 MAG 分析工具。

## 前端结构

- 使用统一分析域配置维护分析域名称、状态、可用模块、数据形态和导航分组，避免首页、顶部栏和侧边栏分别硬编码同一信息。
- 分析工作区顶部以“分析数据”表达当前导入矩阵，避免将丰度矩阵直接称为研究数据集。
- 侧边导航按分析域与科学问题组织图表入口，为后续物种-功能联合和 MAG 模块扩展保留稳定位置。
- 首页流程使用结构化步骤数组渲染共同预处理和三条分析分支，后续调整工具链时只需更新配置内容。
- 响应式样式覆盖桌面、笔记本和窄屏：首页主标题、流程节点和分析分支在可用宽度变化时保持可读。

## 科学表述边界

- `Sample x Species` 描述 Reads 水平物种组成和丰度。
- `Sample x KO` 描述群落整体功能组成，不能单独证明某项功能归属于某个具体物种。
- 在 `MAG x KO` 或其他可靠归属证据接入前，不在页面中声明具体物种的功能来源。
- MAG 入口可以提前纳入导航和首页结构，但在真实分析结果接入前必须保持“规划中”。
