# DiTing 通路图集与 MAG 工具适配

## 范围与入口

在现有群落功能工作区内实现十种图型；继续读取已发布 KO / 通路修订，不重新导入、不修改样本或统计。三个入口的默认视图分别是覆盖率—丰度散点、森林图、雨云图。

| 入口 | 图型 |
| --- | --- |
| 通路概览 | 覆盖率—丰度散点、分组均值哑铃、聚类热图 |
| 组间效应 | Cliff’s δ 森林、效应—显著性散点 |
| 样本分布 | 雨云、小提琴、箱线＋蜂群、ECDF、山脊 |

完整 95 项始终可搜索、排序、查看和下载。概览散点默认覆盖全部；24 项全零指标合并为原点标记，点击可定位完整名称列表，不为避免重叠而抖动其数值。分布视图支持任意多选，每页六项，保存选择顺序；图型、搜索、变换、样本定位与已选集合记录在 URL。单指标点击进入同一版本的样本分布，支持浏览器返回。

## 共享 MAG 工具

`ResearchChartSurface.jsx` 将 ECharts 数据窗口与既有 `ZoomableChartViewport` 对接，复用原有全图/宽度/1:1、缩放滑杆与精确输入、Alt 手势、键盘导航、全局预览、平移摇杆和折叠导航面板。缩放数据视野，不缩放字体。框选时锁定拖动手势，框选只定位结果表与通路集合。

复用 `ChartStyleToolbar`、`PaletteSelect`、`useChartStylePreferences`、共享科研色板、`ChartFrame` 操作区和 `ChartImageExportSettings`。控件按图型启用：散点大小与透明度、适用标注、参考线、密度平滑、热图聚类/色带/转置/指标树/样本标签/格子边界等。分面以分页显示完整面板，不对多面板套统一数据缩放。

热图可对指标平均连接聚类、AD/NC 组内样本平均连接聚类；默认使用 log10(x+1) 后的通路 Z 分数、欧氏距离。通路标准化覆盖全队列，显示单组或转置不改变标准化方向。恒定通路保留在末尾但不参与指标聚类。可切换 log 原值。矩阵颜色表达数值，AD/NC 色条表达分组，并附固定分组图例。连续热图关闭分类纹理，避免色盲模式纹理覆盖数值信息。

## 分布和统计语义

零边界反射高斯 KDE 使用稳健经验带宽，允许调整平滑倍数；恒定或全零数据没有估计轮廓，实际样本仍保留。小提琴和山脊按每组峰值缩放，不能根据面积推断样本量。蜂群在屏幕坐标内确定性避碰；零值过多、宽度不足时保留全部点并提示可能局部重叠。ECDF 对并列值一次跳跃，保留零值，不进行平滑。森林的置信区间和空心/实心显著性语义固定。

所有显示变换、平滑、搜索、框选和分页均不改变后台 p/q 或置信区间。效应—显著性图使用 Cliff’s δ 和 −log10(BH q)，不称为基于倍数变化的经典火山图。哑铃先计算原值组均值，再变换坐标。

## 导出与运行

当前图支持 SVG 与高清 PNG、自定义尺寸、默认导出偏好；按当前图完整集合重建，不导出缩放窗口、导航或框选覆盖层。推荐尺寸依据指标数量适配，导出采用完整通路名称。分布另外支持全部已选通路的完整 SVG 分面，覆盖分页之外的通路；包含版本与全表 BH 说明。

图表使用 SVG 渲染与系列差分更新。试用 Canvas 时发现当前 zrender 在大矩阵切换后的异步绘制可能引用已销毁画布，因此采用 SVG；未修改第三方包。字体族采用合法无引号 CSS 字体列表，避免当前 SVG 序列化器输出嵌套引号破坏 XML，确保缩略图与 PNG 转图可用。

## 验证

定向单元与回归覆盖 KDE 质量与零边界、ECDF 并列零值、蜂群避碰、箱线须、平均连接聚类、十图源数值/pq不变、热图转置数值一致，以及共享视口、MAG 色板、图表注册，共 19 项通过。改动文件 ESLint 与 Vite 构建通过。

本机浏览器脚本：`frontend/.tmp/verify-pathway-gallery.mjs` 覆盖十图渲染、实际 122/63 样本数、全零显示、95 项选择分页、SVG/PNG；`frontend/.tmp/verify-pathway-tools.mjs` 覆盖精确缩放、真实鼠标框选到表、点选与返回、95 项完整 SVG、热图 1:1 与转置。截图及下载结果位于同一临时目录。
