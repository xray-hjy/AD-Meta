# MAG 热图优化

## 数据和选行

- 继承已核验的 MAG v3 百分比矩阵，不再归一化，不改动上游 QC。
- 丰度概览按所选样本总体均值排序；变化模式按 log10(1+%) 的总体标准差排序、排除恒定行；候选对比支持 q/绝对秩效应量条件或完整 MAG ID 清单。
- 所有统计来自同一样本范围中全部代表 MAG 的检验结果，显示条件不会重新计算 BH-FDR。
- 先筛选再限制显示数量；无匹配结果时展示空状态，不补入其他 MAG。
- 明确记录 ID/分类、质量、均值、阈值样本比例及候选条件逐步排除数量。
- 默认 20 行；可取 50、100 或全部匹配项。图形连续显示完整选中集合，取消 50 行分段；列表以 300 行分页，列表换页不改变图形视野。

## 颜色和排序

- 丰度配色列表提供 PuBuGn（默认）、Blues、Viridis、Cividis、Magma、YlOrBr；每项显示渐变预览。PuBuGn、Blues、YlOrBr 去除最浅的 15% 色段，列表明确标注“去浅端”，避免白色端点。
- 行 Z-score 提供 RdBu_r（默认，负值蓝、正值红）、BrBG、PuOr、PRGn 发散色阶，色标关于零对称，恒定行使用所选色阶的中性色，缺失值灰色；原始值保留于悬浮与 CSV。
- 色阶使用 d3 的 ColorBrewer / Matplotlib 插值器，均采样 17 个色标节点。连续与发散模式分别记住选择，SVG/PNG 与配置 JSON 同步当前配色；修改颜色不重新请求筛选数据。列表支持方向键、Home/End、Escape 和点击外部关闭。
- 100% 对应 20×22 CSS px 的单元格步长；默认同时适配视口宽高，支持适应宽度、倍率选择、加减、平移与 Alt+滚轮。图内缩放保持格子比例，固定字号、色标及注释条宽度/高度；标签按可见像素间距抽稀，悬浮保留完整 ID 和原值。小矩阵紧凑排列，热图视口高度控制在 480–720 CSS px 内，轴切换保持视口高度稳定。
- 工作区始终铺满侧栏之外的可用宽度，上游流程、样本筛选、热图和列表外框统一对齐。ResizeObserver 跟踪视口宽高并更新相机边界，不检测浏览器缩放比例，不使用固定最大宽度把页面收窄到中间。导出按完整展示集合和自然格子尺寸独立计算宽高（185 个样本时自然宽度为 4020 CSS px），不受屏幕的响应式放大影响。
- 默认按 AD/NC、批次、ID 排列；可在 AD/NC 各组内或全体样本聚类，也可独立对 MAG 聚类。
- 聚类为 average linkage / Euclidean；在当前颜色变换后的整个展示集合上计算，缩放和平移不会改变排序、颜色范围或标准化。
- 默认显示疾病和批次注释条，年龄/性别可选；注释条使用独立隐藏色标，不干扰主丰度色标。

## 交互与导出

- 复用共享 ChartStyleToolbar，放在可折叠图形标题栏右侧；调整样式不重新请求选行。
- 分析条件显式应用；应用配置保留在 sessionStorage，主动保存按数据指纹写入 localStorage。
- 点击热图单元格/表格 MAG 进入单 MAG 分布；分布页“加入热图候选”保留准确 ID 并追加到手动清单。
- SVG/PNG 仅导出图形、图例、注释，排除 HTML 样式工具栏。导出整个展示集合，不受当前视野影响；排除导航工具栏、预览框和悬浮信息。PNG 根据矩阵尺寸限制到单边 16384 像素、总计 3200 万像素以内；SVG 保留完整矢量细节。
- 下载展示原始矩阵、完整样本×MAG 矩阵、包含条件/顺序/方法/样式的 JSON 配置；保留版本及投影指纹。
