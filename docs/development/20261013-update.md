## 推断与科学口径

- 未调整比较使用双侧 Mann–Whitney U，报告 AD 方向的秩二列相关，所选属提供固定种子、独立组内 bootstrap 区间。
- 年龄 / 性别调整使用完整协变量子集的百分位秩响应、OLS 和 HC3 稳健标准误；检查模型秩、条件数、杠杆值和自由度。无法估计的模型不输出虚构的 p/q 或区间。
- 每个队列、每种模型对完整 322 个目标属做 BH-FDR 校正；检索、分页和所选菌属不缩小检验族。推断条件不通过时仍可查看分布，检验保持暂缓。
- 身份审查登记绑定数据包 fingerprint、Run 集合和公开来源证据哈希；共用 BioSample 不自动认证参与者独立性。现有两个通过核查的队列与其完整协变量条件见接入文档。
- 主数据证据对照只查询当前已发布物种 revision 的属名 / 已核对旧名分类覆盖，保留源 SHA-256 与 revision。主矩阵尺度、标准化与参与者对应仍有待核查，数值复现对照暂缓；单队列显著结果或物种列存在不等于独立跨队列复现。
