# 外部证据评估 v1.3：本轮实施与单一产品边界

日期：2026-10-16。接续 [v1.3 方案](2026-10-15-gmrepo-evidence-release-plan.md)。这是当前实现记录，不是原研究全部补证完成、科学批准或独立验证证明。

## 1. 产品边界修正

用户明确不希望项目分为对外版、内部版，也不希望把组员线下核查变成页面审批流程。因此保持同一套研究产品：

- 撤下新增的“科研待审与资料补交”组件及待审包页面入口，没有迁往另一个内部页面。
- 队列详情改为“研究依据与适用范围”，保留原研究、来源字段/定位、公开编号重叠、数据局限、比较集合与版本依据。
- 不展示人员、签署日期、责任分工、补交任务、下一动作或空白的审查记录；过程性 `SCIENTIFIC_REVIEW_PENDING` 不作为研究内容反复展示。
- 实质限制继续保留：分组不明、参与者对应不足、完整病例不足、来源失效、主外数值不可比等。隐藏人员流程不解除任何计算资格，也不制造“已审核通过”。
- 一直沿用主分析主题、无侧栏的全宽工作区和既有质量/分布图。物种/MAG 对象、主修订、来源范围与返回入口保持贯通。

底层来源读回、比较范围绑定、历史记录与复算能力继续保障结果可靠；仓库中的技术校验脚本不是第二套产品或必须由用户操作的审核后台。本轮未导入人工意见，未代签或伪造复核。

## 2. 来源补证进展

不可变 GMrepo 包仍为 `2026-10-09-v1`：13 个接入项目、1269 Run、800 完整 profile、322 属、5 个分布队列、2 个原有可检验队列。没有扩大检验资格或覆盖旧包。

研究登记为 `gmrepo-research-ledger-2026-10-16-v3`：14 项来源记录均补入官方项目名称/描述，47 份登记来源本地读回验证，另有原来 9 份发现获取回执。新增归档在 `ADMetaData/reference/gmrepo/release-sources/2026-10-15-v1` 至 `v4`，包括实际失败响应；原件与候选登记均独立保存。

新增原论文/项目记录形成的具体边界包括：

- PRJEB49329 原研究含 AD/MCI/SCD，SCD 不直接当 NC；PRJEB50447 个体临床资料要求合理申请和伦理条件，本轮未联系作者或提交申请。
- PRJNA1028813 虽项目题名包含 Metagenome，原文方法为 16S / LotuS2 / SILVA / PICRUSt2；不据题名改判 WGS，平台描述冲突保留。
- PRJNA496408 原文存在研究子集及配偶对照；同 accession 多论文不自动作为独立研究。
- PRJNA633959、PRJNA770746 等取得 ENA 项目 Run 导出，但实验、标本和参与者仍不能仅凭数量一一等同；原有描述性队列没有因此开放检验。
- PRJEB77146 仍仅来源发现、未接入；认知主诉/排除痴呆的人群不是临床 AD/NC。

覆盖仍不完整：GMrepo 项目选择接口实际返回 405/500，静态全项目导出返回 HTML；宽泛文献检索没有完整取回。定向 WGS 文献式 140/140 的分页取得，不等于 140 项全部人工筛查，更不等于全库覆盖。部分原文/个体附件仍未取得。获取失败不是零结果，来源可下载也不等于所有内容已经科学确认。

## 3. WGS 是真实扩展，但必须标明实际来源

新增 PRJNA798058 的原研究作者公开处理数据，来源是[原论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC10680783/)及[作者 Zenodo 记录](https://zenodo.org/records/14991167)，**不是 GMrepo WGS 数据接入**。

- 从公开 RData 的未按显著性筛选表提取：164 名参与者，临床前 AD 49 / 生物标志物阴性 CN 115，175 属层和 505 物种层原分类特征；5 个没有纳入元数据的 profile 排除。
- 只用 base R 读取指定数据表，不执行作者分析脚本。提取脚本、归一化准备脚本、原文件哈希和派生清单均保留。
- MetaPhlAn3 / 原分类版本和相对百分比明确标注。保留原分类 ID，不冒充已统一的当前 NCBI 物种编号。
- 页面提供显式特征选择、散点、零值/检出/分母及中位数；主对象仅按唯一精确属名补充冻结的 WGS 属级阶段背景。无匹配不替换默认特征。
- 与 GMrepo 的临床 AD/NC 分开，不计入 5 个 GMrepo 队列，不新增 WGS p/q，不将 HUMAnN 通路当 KO，不认证 MAG/物种复现。
- 来源记录许可为 `other-open`，未推断商业再分发授权；本轮本地派生包未作为仓库公共运行包重新分发。

本地派生位置：`ADMetaData/reference/external-wgs/PRJNA798058/2026-10-15-v1`。新部署不自带作者文件时，WGS 分支明确不可用，原 GMrepo 功能不因此失效。

## 4. 关系范围与主数据事实

5 个 GMrepo 分布队列、当前主队列范围、WGS 来源范围形成 7 个节点 / 21 对关系。逐对绑定左右清单指纹，比对公开 Run / BioSample，保留参与者覆盖及原研究关系线索。不输出独立验证数量；相同数量或无相同编号均不能证明参与者独立。WGS 作者 164 人与 ENA 164 Run 尚无逐人到 Run 的公开对应，不用同数量伪造关联。

主队列 185 个 CRR（AD 122 / NC 63）编号已存在并核对；不是仍在向用户索取这份编号清单。当前仍缺物种/KO 固定矩阵的实际生成脚本/运行依据、单位与归一化，以及匿名参与者/重复采样关系。项目流程概述、CRR 唯一或 MAG 自身方法记录不能自动填补这些缺口。因此主外数值复现仍不成立。

## 5. 固定评估与独立离线复算

页面、报告、JSON 与 `evaluationId` 绑定；历史页面按 ID 读回，不静默换成当前重新生成结果。新增参考队列离线复算 ZIP：含全特征输入、完整预期统计、独立 `replay.py`、依赖版本与文件清单。依赖变化时拒绝用旧 ID 导出新的替代复算包。

浏览器实际下载后，在独立目录用 Python `-I` 运行，不导入项目 app 或连接主数据库：两队列各重算完整 322 属的未调整/调整/FDR，并保留三描述队列不做检验；从提取后的作者表重算所选 WGS 阶段分布。容差绝对 `1e-10`、相对 `1e-8`。校验通过并非独立科研认证。

复算不涵盖原始 FASTQ、主物种/KO 矩阵、二进制 RData 再提取、原论文解释或分类映射的独立确认；对象解释仅归档，其所引统计输入参与校验。

## 6. 本机验证

- GMrepo 后端 9 文件共 74 项测试通过。系统原 pytest 临时目录拒绝访问，改用本工作区全新临时目录重跑；不是忽略失败断言。
- GMrepo / evidence 前端 8 文件共 28 项测试通过；包含无人员/签署/任务 UI 且实质限制保留的回归检查。
- 12 个后端目标文件 mypy、前端 TypeScript、OpenAPI 契约读回、修改页面 ESLint 和生产构建通过。
- `frontend/scripts/verify-evidence.mjs` 实际浏览器 20 组链路检查通过：目录/检索/质量/来源、WGS、390px、单一产品边界、物种/MAG 来回、固定评估与下载、独立 JSON 校验及离线统计复算；主题读回与主分析一致。
- 本机产物位于 `.tmp/gmrepo-evidence-qa/`，含 `verification.json`、`standalone-replay-result.json`、实际下载包和截图。它们不是全部原研究证据已完成的证明。

后续材料齐备后更新同一套研究说明和相应范围，不新增对外/内部版本，也不以统一“待审”文案代替具体证据局限。
