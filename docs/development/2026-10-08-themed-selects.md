# 默认下拉菜单与物种 / 功能 Top N 面板

## 本次改动

- 普通原生下拉菜单改为项目已安装的 Base UI Select。菜单采用圆角、浮层阴影、主题选中状态和勾选标记；保留原有选项值及筛选事件契约。
- 覆盖分析运行、科学筛选参数、箱线图特征数量、完整结果排序、图形设置与导出，以及 MAG 排名、分类、质量、来源映射和热图设置。
- 使用 body Portal、固定定位和边界避让，避免菜单被卡片裁切。菜单复制触发器所在工作区的主题色：物种蓝、功能青、MAG 玫红。
- 菜单内按下鼠标或 Esc 不会同时关闭外层图像导出 / 设置浮层；支持键盘选择。

## Top N 适配

社区图表共享新的数量面板，包括物种与 KO 丰度、分类组成、KO 贡献、差异丰度热图、KO 阈值分布、差异 KO 和 PCA。包含常用数量、自定义整数、滑条、推荐数量、有效范围、当前可选数量及明确应用操作。

| 视图 | 可用数量范围 | 语义 |
| --- | --- | --- |
| 物种 / KO 丰度 | 1–500 | 当前排名的展示数量 |
| 分类组成 | 1–50 | 分类组成项数量，使用分类数而非物种数作为可选数量 |
| KO 贡献 | 1–100 | KO 展示数量 |
| 差异丰度热图、KO 阈值分布 | 1–200 | 保留现有界面数量范围 |
| 差异 KO | 1–100 | 显著结果展示上限，空结果保持为空 |
| PCA | 2–500 | 特征选择与重新计算，明确说明会改变坐标和解释率 |

- 点击“应用”或输入框 Enter 才提交数量；输入、滑条和预设选择均先修改草稿。
- “全部匹配”仅在当前可选数已知且未超过对应接口上限时启用；提交实际数量，社区接口不使用 MAG 的 `topN=0` 语义。
- 参数预设改为支持范围内的任意整数；q 值、检出比例等科学参数仍按既有规则处理。
- PCA 不提供仅用于展示的“全部匹配”按钮。
