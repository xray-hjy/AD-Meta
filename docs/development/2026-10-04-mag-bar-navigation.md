# MAG 条形图连续导航与全部选择

## 选择与数据边界

- 图表显示数量保留 Top 10 / 20 / 30 / 50，加入“全部 MAG”。全部指当前样本筛选与 MAG 搜索范围中的全部匹配结果，继续按图表排名依据排序。
- `magComparisonSelection.js` 使用原有每页最多 300 项的接口，固定 revision、搜索、样本范围和排名，合并全部响应。传递取消信号，并核对版本、数量及 MAG ID 唯一性；不把未完整读取的集合显示成全部。
- 图表选择与结果列表分页、列表排序独立。后端溯源接口约定 `topN=0` 为全部匹配 MAG，避免空切片；不改变原始百分比、组均值、检验族或 FDR。

## 共用交互

- 新增可复用 `ZoomableGroupedBarChart`，接入已有公共 `ZoomableChartViewport`、Radix 缩放滑条、平移摇杆和全局预览。缩放工具栏位于右上方，摇杆与预览固定右下角。
- 固定高度视口内连续显示全部选中条目；只绘制当前可见范围的条形和标签，视野改变不进行新的数据筛选。SVG 为主渲染，Canvas 仅用于缓存缩略图。
- 保留圆角、数值、网格、柱宽、精度、字号、图例和动画设置；加入横向/竖向切换，沿用主题色选中状态，切换只改变绘图方向。轻量淡入遵守减少动态效果偏好。
- 标签按实际字体宽度和边界显示前缀加 `...`，完整名称保留 title/悬浮；过密的标签降采样。数值标签检查相邻碰撞，避免缩小时重叠。条形图相机只缩放、平移类别轴，丰度轴始终使用可用绘图区；热图继续使用公共双向相机。
- 悬浮按原始 MAG 索引返回丰度，缺失组保留“未提供”；点击仍打开对应 MAG 的分布。色盲友好模式提供两组方向不同的纹理。

## 导出与验证

- 独立 ECharts SVG 导出完整选中集合及当前方向/样式，排除屏幕相机、缩放工具栏、摇杆、预览和悬浮信息。PNG 从完整 SVG 生成，限制单边 16384 与总计 3200 万像素。
- 前端 7 个相关测试文件共 47 项通过；后端图表溯源测试 2 项通过，修改文件 ESLint 和 Vite 构建通过。
- Edge 实测完整 872 项读取、缩放滑条、摇杆平移、方向切换、窄屏和点击分布联动，无页面错误。水平全量 SVG 自然尺寸 1500×29752，约 1.2 MB；本地后端已重启并确认 `topN=0` 的溯源包含 872 个 ID。
- 实际全量 PNG 为 826×16384，约 4.4 MB；竖向全量 SVG 自然宽度 29813，约 1.14 MB。两种方向导出均不含导航控件，PNG 面板文案明确按图形尺寸适配。

## 区间拖动与动态刻度补充

- 新增公共 `ChartCategoryRange`，两端 Radix 手柄调整范围，中间窗口可整段拖动、方向键移动；底部使用主题色与全量丰度轮廓。轮廓最多 240 个装饰采样段，索引仍覆盖每个 MAG。
- 区间与缩放滑条、摇杆和预览共用相机；转置保留同一类别区间，不沿用几何旋转后的倍率。区间拖动按动画帧合并更新，阻止 Radix 手柄与窗口平移的事件冲突。
- `groupedBarScale` 从可见类别的全部组均值计算数值轴，包含零点、预留标签空间，并按屏幕长度生成合理刻度和精度；空值不参与计算，全零范围使用有效默认轴。原始百分比、排名、数据选择与完整导出均不变。
- 相机导航新增可选单轴模式，热图默认双轴行为保留。条形图缩略图铺满预览区域，独立换算横纵坐标，避免全部 MAG 模式下预览被压成细线。
- Edge 实测 872 个 MAG：第 621–636 项浏览区间的数值轴从全局 0–3% 调整至 0–0.035%，拖动两端和整个窗口、摇杆、转置、全图恢复及 800 px 窄屏通过，无页面错误。
- 本次包含区间、动态轴、转置、数据选择、样式与热图回归的 10 个测试文件共 65 项通过，修改文件 ESLint 和 Vite 生产构建通过。

## 图例、柱组标记与自适应摇杆

- AD/NC 图例支持点击、Enter 和空格切换可见分组，提供明确选中与隐藏状态；隐藏组从屏幕柱形、数值、提示、动态轴、区间轮廓和缩略图中同步移除。保留 MAG 排名、当前浏览区间和原始数据，重置样式恢复全部分组。
- 工具栏加入可选“分组标记”：以虚线分隔相邻 MAG 的柱组，在各柱对应位置显示 AD/NC。支持两种轴方向；空间不足时简化标记，避免重叠。完整导出保留图例选择状态、虚线和可见组名。
- 另设默认开启的“分组悬浮”：同一 MAG 内按左右半区识别 AD/NC，横向柱图按上下半区识别。所在半区浅色高亮，当前视野内同组全部柱形一起强调，另一组柱形、数值和组名标签淡化至 30%；提示只显示鼠标所在 MAG 的该组原始丰度；空白区域也可识别，缺失值保留“未提供”。仅在悬浮柱组的组内中线绘制虚线，离开或平移后消失；单组可见时不显示中线。关闭后停止提示、高亮与组内虚线，状态保存至本地；相邻 MAG 的分隔线开关、图例和点击分布独立，临时悬浮标记不进入导出。
- 公共 `chartPanSpeed` 按各轴的图形范围、可见数据范围和屏幕视口计算速度，而不是使用样本数量。远距离全推杆以约十秒遍历范围为目标；基础速度按视口计算，点按约移动 18% 视口，中心杆保留死区与细调曲线，连续推杆在 600 ms 内逐步加速。
- 相机提供通用几何信息，条形图和热图使用同一速度策略。更新倍率、尺寸或方向只更新速度，不重置持续移动的帧时钟；边界、失焦、释放指针和卸载继续停止运动。
- Edge 实测完整条形图长按 1.1 秒移动约 63 个 MAG，SVG 未被重建；热图 100% 至 200% 时纵向速度从约 1.87 增至 3.79 CSS px/ms，持续拖动保持倍率与 SVG 身份。图例、柱组标记、带隐藏组的全量 SVG 导出均通过，无页面错误。

## 2026-10-05 分组悬浮命中调整

- 悬浮识别从整片类别半区改为实际 SVG 柱体。利用浏览器对柱体路径的命中检测适配圆角、负值、裁切与两种轴方向；缺失值和零值不产生悬浮目标。鼠标移至空白或类别文字时清除提示和同组强调。
- 保留当前视野内同组柱体整体高亮、另一组淡化以及独立的柱组分隔线。装饰网格、提示背景和数值文字不拦截柱体鼠标事件。点击定位 MAG、图例选择与悬浮开关保持独立。
- 验证：16 项相关测试与 ESLint 通过；Edge 实际鼠标检查横向/竖向柱体命中、空白退出、标签不触发、同组整体高亮、关闭悬浮和单组可见，无页面异常。
