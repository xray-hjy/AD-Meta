# 查询与实体选择自动补全

## 实现

采用 MIT 许可的 `@base-ui/react` 1.8.0：自由关键词使用 Autocomplete，确定实体选择使用 Combobox。组件共用两行候选、类型徽标、焦点反馈、圆角半透明弹层，以及方向键 / Enter / Escape 操作。中文输入法确认不会提交查询。已有主题色从所属工作区传递到 Portal；尊重减少动画设置。

候选检索与图表计算分离。键盘高亮候选不更新图表；关键词仍可直接提交。候选只提供查询线索，名称近似匹配不改变 GTDB—NCBI/Bracken 的映射证据。

| 入口 | 数据与行为 |
| --- | --- |
| MAG 丰度 / 单 MAG 分布共享搜索 | 完整代表目录；ID 与分类关键词区分。确认候选即检索，单 MAG 当前选择保持独立。 |
| 单 MAG 选择 | 可搜索完整目录，分页不限制候选；仅确认已知实体提交稳定 ID，自由输入不提交新 ID。 |
| 热图 ID / 分类搜索 | 编辑草稿，“应用设置”后更新热图。 |
| 热图手动清单 | 搜索名称加入完整 ID，去重、标签删除；保留多行粘贴。全部操作仅编辑草稿。 |
| 分类 / 质量目录检索 | 使用完整目录，结果同时遵守当前分类、质量区间、框选条件。候选数量为完整目录数量。 |
| 来源聚类检索 | 完整聚类与代表 MAG / GTDB 物种，确认聚类编号或代表 ID 后搜索聚类。 |
| crosswalk 检索 | 完整已存储 crosswalk，包含 MAG、GTDB、NCBI、Bracken 名称；近似名称必须显式确认。 |
| 单样本选择 | 完整样本列表中的稳定 sampleCode；可按编号或 AD/NC 过滤候选。 |
| 箱线图物种 / KO 候选搜索 | 沿用后端完整范围检索，自动补全确认后加入已有选择池，仍需应用选择。 |

已检查的其他入口：子集样本搜索已有可筛选的复选候选列表与应用按钮；审计筛选器已有异步搜索和键盘候选列表，因此保留现有选择模型。完整结果查询包含样本、分组、特征及注释等多种字段，继续提供自由关键词查询，不用当前页内容冒充完整候选库。年龄、阈值、缩放等数值输入保留数值控件。

## 完整目录与响应限制

- 代表 MAG（当前 872 个）通过 revision 对应的 `/api/mag/catalog` 缓存，复用分类与质量目录查询；本地索引只使用分类层级和稳定 ID，不使用参考 ANI 等数字做名称匹配。
- 名称 / ID 排序：完整 ID、ID 前缀、名称完整匹配、名称前缀、包含匹配、标记为“相近名称”的分类提示。相近 ID 不做容错替换。
- `/api/mag/suggestions` 提供 lineage / crosswalk 类型化查询，返回当前数据 revision、总候选数量和前 20 个条目，最大 50 个。候选计数按唯一 MAG 去重。
- 远程输入防抖 200 ms，使用 React Query 的 AbortSignal；新的输入隐藏旧候选，过期响应不覆盖当前列表。仅展开时检索，查询可缓存。
- 弹层只挂载前 20 个候选，更多时提示继续输入。当前完整本地目录规模无需长列表虚拟化；远程目录不下载所有记录。
- 版本变化由已有 revision 校验返回 409，候选、搜索结果及图表不会跨版本拼接。
- 完整 MAG / 聚类 ID 的查询优先精确匹配，防止 `MAG_A` 顺带匹配 `MAG_A1` 或聚类 `c1` 匹配 `c10`。分类名称保持原关键词检索语义。统计检验族、丰度和映射状态不变。

## 验证

新增组件测试覆盖键盘确认、中文输入、取消与清空、固定实体选择、完整目录、名称容错边界、手动清单去重 / 删除、异步请求取消与旧候选隔离。后端测试覆盖分类计数、聚类去重、输入约束与精确 ID 优先。

实际浏览器检查 MAG 丰度搜索、单 MAG 选择、热图草稿与手动清单、来源 / 映射自动补全；未出现页面脚本错误。QA 脚本与截图在忽略目录 `frontend/.tmp/`，不作为源码交付。
