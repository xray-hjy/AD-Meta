# 20261010更新

本次主要更新正式首页 `/`。基于 `49750bb`（20261008 更新）继续开发，分析工作区的数据计算与 API 契约没有变更。

## 首页布局与内容

- 首页整理为首屏入口、可视化展示、数据来源与分析入口三个大区块。
- 物种、KO、MAG 和图表自定义能力分别展示，使用工作区真实截图；文案集中维护，说明可查看什么、如何调整图表。
- 顶部状态栏与导航保持固定悬浮；入口连接现有分析路由和相应数据集。
- 首页只展示工具能力与研究线索，不把截图或 AI 候选特征写成临床诊断、已验证标志物或因果结论。

## 图集和滚动交互

- 使用 npm 锁定的 Swiper 14.3.0，采用立体画廊；横图、热图和竖向设置面板按真实比例适配。
- 普通滚轮切一张，大幅或连续滚动可连翻；停下后吸附完整图片，支持反向回看。
- 看完本组图集后进入相邻模块；文字使用可取消的进出动画，上下文保持相同排版并淡化显示。
- 首屏到图集、图集到数据区域增加位移、缩放、透明度衔接；620ms 缓动避免滚轮跳步时直接换状态，反向滚动还原。
- 窄屏、矮屏与减少动态效果模式使用普通文档流和按钮图集；图片可在原生 dialog 中放大。

## Logo 分层动画

- 接入用户提供的顶部、中间连接网络、底部三个真实 SVG 部件，共用画布拼合。
- 原稿保存在 `frontend/src/assets/brand/logo-parts/originals/`，展示稿统一 viewBox；中间件展开为 SVG 属性，避免样式类污染。
- 上下对合、弧线汇合、立体翻合、网络唤醒、轻弹扣合全部采用；开场和点击重播随机选择，避免连续重复。
- 重播、中断和退出释放动画；减少动态效果时显示静态 Logo。

## 前端目录与维护入口

- `frontend/src/pages/home/HomePage.jsx` 负责组合，`homeContent.js` 维护文案、截图元数据和链接。
- `components/` 放首页 UI，`hooks/` 连接 React 生命周期，`motion/` 放交互控制器和参数，`assets/` 放截图。
- 将大块布局 CSS 按职责拆成 `home-base.css`、`home-header.css`、`home-hero.css`、`home-foundation.css`、`home-dialog.css`；图集、正文、开场和区块过渡分别维护。
- 移除旧全局 `src/styles/home.css` 及其 import，所有首页规则限制在 `.admeta-home`。
- 新增[前端开发导航](../../frontend/README.md)，完善[首页维护说明](../../frontend/src/pages/home/README.md)，方便定位修改入口、了解依赖边界和验证方式。
- Demo 和其固定版本库留在 docs 作为设计记录，不参与正式应用构建。
- Swiper、监听器、计时器、动画帧与 WAAPI 在离开首页时清理，支持 StrictMode 和媒体条件切换。
