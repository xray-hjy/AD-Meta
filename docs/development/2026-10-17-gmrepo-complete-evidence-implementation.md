保持一个产品、全宽页面，沿用主分析主题。既有质量图、样本分布、原研究说明与 WGS 参考保留。

1. 对象评估增加主外森林图，未调整与年龄/性别调整分开。无统计量的队列保留空行，不画成零效应；点击外部队列定位原分布，点击主队列定位固定 185 样本的 ECDF。
2. 新增 `/reference/gmrepo/comparison`：完整目录 1,113 项，175 主外唯一对应、785 仅主队列、6 对应歧义、147 仅外部参考。未知/歧义不强行合并；歧义对应的外部属仍单列可选，不被主映射状态吞掉。矩阵和表格分页同步，全部候选可检索；空格不是零。
3. 主物种完整结果可以按特征 ID 勾选多项，携带固定 revision 进入属级对照，同属多个物种形成一个属级候选。无法对应的输入单独提示，不代入默认属。
4. 固定候选后，页面、报告、JSON、复算及图像使用 evaluationId；主外图采用同一口径，不按方向计独立支持票数。
5. 复用 MAG 已有科研配色、样式、镜头缩放、复位、预览、导航与 SVG/高清 PNG 导出。森林/矩阵没有需要改变统计集合的框选，所以不显示无效框选按钮；未改变 DiTing 默认工具语义。

主外同属方向、区间和 q 分别解释，不把属结果称作所选物种/MAG/功能的复现。KO 与 DiTing 不生成虚构的 GMrepo 功能外证。

## 固定结果、复算及部署

新增接口：

- `GET /api/references/gmrepo/comparison-catalog`：完整检验后再查询/分页；支持固定 `sourceRevision/datasetSlug`，以及 `speciesIds` 的归属过滤与未对应清单。
- `POST /api/references/gmrepo/candidate-comparison`：明确候选 ID 集合，拒绝重复/未知 ID，冻结结果。
- `GET /api/references/gmrepo/candidate-report?evaluationId=...`：读回同一固定记录。
- 原 `evaluation-package/recompute-package` 支持单对象及多候选，旧 ID 保留为历史，不重新生成冒充旧结果。

离线复算 ZIP 包含公开/本地可用范围内的主种级观察、分类与协变量、派生完整属级矩阵、主外完整期望统计、固定评估和独立脚本。解压后以 Python `-I replay.py <目录>` 实际运行，独立重做种→属求和、966 属统计、外部各 322 属及单属区间；原作者 WGS 阶段分布另保留其描述性复算。不重跑 FASTQ，不认证科研批准、研究独立或原作者统计模型。

本地支持包：`ADMetaData/reference/gmrepo/delivery/2026-10-17-v6-final2/gmrepo-evidence-support.local.zip`，约 22.6 MB，201 文件，包含固定参考核心、126 份来源依赖、全库分页、主属级缓存和 WGS 原来源依赖。发布前及解压至新目录后均校验，逐项确认 126 份登记来源均在包内，禁止覆盖已有目录。

```powershell
cd backend
.venv/Scripts/python.exe -m app.cli.package_gmrepo_evidence --check ../ADMetaData/reference/gmrepo/delivery/2026-10-17-v6-final2/gmrepo-evidence-support.local.zip
.venv/Scripts/python.exe -m app.cli.validate_gmrepo_ledger
```

此包仅为本地研究/部署支持，不是公开或商业再分发授权，不上传外部。它不含项目数据库和全部代码；部署需相同代码及包含指定物种 revision 的项目数据库。新导入产生新 revision，不能冒称原固定 ID 已在新库复现。无需数据库的数值核验使用每次评估导出的独立复算 ZIP，而不是假称支持包是数据库备份。
