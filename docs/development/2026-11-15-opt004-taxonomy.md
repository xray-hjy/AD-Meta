# OPT-004 分类层级图空间、浏览与数值解释

本地修改与验证，未部署、未导入源数据、未修改飞书问题状态。实际查看了该条目的矩形树图截图与旭日图布局示意。

## 实现

- 矩形树图取消高度 × 1.7 的宽度限制，使用实际容器宽度重新计算 ECharts 布局；提高默认最小高度至 760px，支持手动 760–1800px、自动高度及全屏。尺寸变化通过现有 ResizeObserver 路径重新测量；不拉伸旧图。
- 点击节点聚焦当前分支；明确默认显示三层，可继续深入。提供完整路径、祖先按钮、返回一级、恢复全图、名称/路径查找和键盘按钮。完整名称与数值另在节点详情提供，标签截断不改变节点或分类关系。
- 使用 ECharts 原生矩形树标签代替原先运行时额外叠加的 graphic 标签，导出按目标尺寸重新布局、保留聚焦分支。矩形树分支切换以独立实例清除旧标签，避免 ECharts 合并旧视图产生残影。说明导出不是截取漫游后的像素窗口。
- 旭日图保持等宽高正圆，取消为固定侧栏预留的空间；压缩外圈标签长度以预留安全边距，完整名称通过悬停、查找与详情获取。圆形图尺寸变化后显式同步实例尺寸，避免初次渲染旧尺寸裁切外圈。
- 图例为约 91% 不透明背景的毛玻璃卡片，默认右下；通过手柄拖动或方向键移动，限制在图表区域内。支持收起、隐藏、显示、复位；尺寸变化及展开时重新约束。窄屏变为普通下方卡片。图例值始终表示完整范围，不随分支误换分母。
- 旭日图 SVG 导出包含完整图例，并固定重新排在右侧，忽略实时拖动位置；导出圆半径根据目标尺寸布局，保持正圆。图片包含范围、样本数和数值口径说明。
- 放射树保留展开/收起、增加漫游和明确解释；分支聚焦时重新创建该分支的实例，避免 ECharts TreeView 更新旧边时出现 `__edge` 空引用。它是分类层级树，不是基于序列推断的系统发育树。
- 桑基图保留现有列预算、横纵浏览和完整 PNG 导出；查找结果可显示详情、高亮并定位。节点/边说明分类归属与丰度汇总，不称作迁移/物质流动。

## 数据口径与合并追溯

- 分类树原有计算使用所选样本物种输入值之和，本次不改成均值、不重新闭合、不改变剪枝规则。
- 已声明相对丰度单位时，节点值明确为“样本相对丰度之和（比例累加，非百分比）”；同时显示所选 N 个样本均值（节点值 / N × 100%）、整图占比（节点值 / 原根总和）与父级占比。未知单位保留为源丰度，样本数未知时不推算均值。
- 门→纲→属→物种是当前投影层级；并不宣称图包含完整的界门纲目科属种。
- 保留原分类树每层长尾规则，新增 sourceMembers 与 aggregationKind，记录合并节点的直接成员及值。桑基额外布局压缩同样保留来源成员、规则类型、完整路径，并输出列预算与子节点上限。
- 可从 Other 进入成员详情和成员分页，成员内的聚合可继续查看；直接成员的合计等于合并节点值。真实未分类与展示合并分别说明。
- 旭日图既有整图 <1% 门级合为 Others 的展示逻辑保留并明确说明；不同于源树的父级内剪枝。
- 所有图保留原筛选与合并审计、完整结果查询和下载。前端查找检索当前展示节点，聚合内部分类可通过成员详情或完整结果查询访问，不伪称全物种索引。
- 投影缓存 schema 升至 1.8，避免旧缓存缺少成员元数据。

## 真实源表核验

只读使用现有 normalize_metaphlan 解析 taxonomy.tsv 与 samples.tsv 后运行实际分类树及桑基投影函数：

- 185 样本，1,828 物种；分类树根总和 **185.0000015**。
- 源矩阵总和 **185.0000015**，桑基深度 0 节点总和 **185.0000015**，数值守恒。
- 总和 / 185 × 100 = **100.00000081081082%**；因此截图的“185”是样本比例累加值，不能解释为 185%。接近整数的偏差来自源表舍入。
- 真实源表计算结果通过只读浏览器测试路由注入隔离测试容器，未创建或修改已发布数据版本；截图标识只读验证版本，不代表生产部署。
