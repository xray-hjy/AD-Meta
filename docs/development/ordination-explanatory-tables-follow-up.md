# PCA / PCoA 解释性表格后续实施方案

## 文档状态

- 状态：待实现设计方案
- 记录日期：2026-08-11
- 适用范围：物种丰度矩阵的 PCA 与 PCoA
- 当前行为：本文件不代表功能已上线，不改变现有计算、API、缓存或前端展示

## 目标与边界

当前 PCA 和 PCoA 已能展示样本排序坐标，但对主成分贡献、组内离散、特征值诊断和特征筛选过程的解释仍不完整。后续应在不重复计算、不改变现有统计口径的前提下，补充可追溯的解释性表格。

本方案遵循以下边界：

1. 后端负责生成科学计算结果和派生统计量，前端不根据图中坐标自行推导。
2. 样本坐标、解释性表格、筛选审计和统计检验必须绑定同一 `projectionKey`、样本范围、参数与计算版本。
3. 表格是对当前分析结果的结构化披露，不等同于完整结果下载或论文级导出。
4. PCA 与 PCoA 的数学含义不同，不把 PCA loading 的概念套用于 PCoA。
5. 当前 Manifest 尚未确认丰度单位、标准化方法和协变量；新增字段不得突破现有探索性分析边界。

## 1. PCA 主成分贡献物种表

### 科学问题

回答哪些入选物种对 PC1、PC2 的方向和构成贡献较大，辅助解释样本在 PCA 空间中的分离方向。

### 建议字段

| 字段 | 含义 |
| --- | --- |
| `feature` | 物种名称 |
| `pc1Weight` / `pc2Weight` | PCA 模型对应主成分的特征权重 |
| `pc1ContributionPct` / `pc2ContributionPct` | 权重平方在对应主成分中的占比 |
| `dominantComponent` | 绝对贡献更高的主成分 |
| `selectionRank` | 该物种进入 PCA 前的总丰度排名 |

### 计算约束

- 权重来自与当前样本坐标完全相同的 PCA 模型，不重新拟合第二个模型。
- 当前逐特征 Z-score 标准化策略必须随结果返回。
- 正负号只表示主成分轴方向，不得表述为 AD 或 NC 富集。
- 前端默认按绝对权重或贡献率排序，但同时保留原始有符号权重。
- 表名优先使用“主成分贡献物种”，列名使用“权重”；若未来提供变量与主成分的相关 loading，必须与模型权重分字段存放。

## 2. PCoA 样本质心距离与组离散度

### 科学问题

描述每个样本相对本组质心的离散程度，并解释 PERMDISP 所比较的组内离散差异。

### 样本明细字段

| 字段 | 含义 |
| --- | --- |
| `sampleId` | 样本编号 |
| `group` | 当前分组 |
| `distanceToGroupCentroid` | 到本组质心距离 |
| `withinGroupRank` | 组内距离排名 |
| `includedInPermdisp` | 是否参与当前 PERMDISP |

### 分组摘要字段

| 字段 | 含义 |
| --- | --- |
| `group` | 分组 |
| `sampleCount` | 有效样本数 |
| `meanDistance` | 平均质心距离 |
| `medianDistance` | 中位质心距离 |
| `standardDeviation` | 标准差 |
| `iqr` | 四分位距 |

### 计算约束

- 距离必须使用当前 Bray-Curtis 距离矩阵产生的全部正特征值 PCoA 坐标计算，不能只使用页面显示的 Axis 1 与 Axis 2。
- 样本坐标、质心距离和 PERMDISP 必须共用同一距离矩阵指纹。
- 单组范围可以提供描述性质心距离，但不得显示组间 PERMDISP 推断结论。
- 被零总量或其他权威规则排除的样本不得混入距离摘要，应在筛选审计中说明。

## 3. PCoA 特征值与负特征值诊断

### 科学问题

披露经典 PCoA 对距离矩阵的分解结果，并说明负特征值对二维解释率和欧氏表示的潜在影响。

### 建议字段

| 字段 | 含义 |
| --- | --- |
| `axis` | 排序轴编号 |
| `eigenvalue` | 原始特征值 |
| `sign` | 正、零或负 |
| `positiveVariancePct` | 以正特征值之和为分母的解释率 |
| `cumulativePositiveVariancePct` | 正特征值累计解释率 |

### 诊断摘要

- 正特征值数量与总和；
- 负特征值数量与绝对值总和；
- `abs(负特征值之和) / (正特征值之和 + abs(负特征值之和))`；
- 距离类型与距离矩阵指纹；
- 负特征值校正方法，当前应明确标记为“未应用 Lingoes / Cailliez 校正”。

### 展示约束

- 默认可展示前若干轴，完整特征值序列通过分页表或下载获取。
- 不把正特征值解释率描述为 PCA 式“总方差解释率”；界面需要保留 PCoA 语义。
- 若未来新增负特征值校正，必须提升计算版本并让校正方法进入缓存键和投影元数据。

## 4. PCA / PCoA 物种筛选明细

### PCA 明细

PCA 当前按当前样本范围内的总丰度排序选择 Top N。后续应记录：

| 字段 | 含义 |
| --- | --- |
| `rank` | 总丰度排名 |
| `feature` | 物种名称 |
| `totalAbundance` | 当前范围总丰度 |
| `cumulativeCoveragePct` | 累计丰度覆盖率 |
| `status` | 参与计算或未参与 |
| `reason` | 位于当前 Top N 或超出当前 Top N |

在上游丰度尺度未确认前，不为 PCA 临时增加依赖单位的最低丰度阈值。若以后改变特征选择策略，必须作为新策略和新计算版本实施。

### PCoA 明细

PCoA 继续使用现有可审计过滤管线，逐物种披露：检出样本数、检出率、平均与最大相对丰度、保留状态、排除原因和排名。不得重新引入已废弃的“Top 500 参与距离计算”表述。

### 统一要求

- PCA 与 PCoA 可以共用分页、筛选、排序外壳，但必须使用各自的列定义和原因词典。
- 明细请求必须携带并校验当前投影身份，禁止显示来自旧样本范围或旧参数的结果。
- 表格中的“物种”不得泛化显示成“特征”；底层契约仍可使用通用 `feature` 字段。

## 5. PCA 主成分解释率表

### 建议字段

| 字段 | 含义 |
| --- | --- |
| `component` | PC 编号 |
| `eigenvalue` | 主成分特征值 |
| `explainedVariancePct` | 单个主成分解释率 |
| `cumulativeVariancePct` | 累计解释率 |

### 分阶段实现

1. 第一版只披露当前模型已经计算的 PC1、PC2，不伪造其余主成分。
2. 若增加碎石图或完整解释率表，后端应一次性计算经过审核数量的主成分，并由同一模型返回坐标、特征权重和解释率。
3. 主成分数量规则应受到 `min(样本数, 入选物种数)` 的数学边界约束，并写入计算元数据。

## 6. PCoA 排序轴关联物种分析

### 当前结论

暂不并入普通 PCoA 表格。PCoA 不存在可直接读取的 PCA 式 loading；物种与排序轴的关联需要新增统计方法，属于独立分析能力。

### 实施前必须确认

- 采用 Spearman 相关、向量拟合及置换检验，还是其他经审核方法；
- 使用原始丰度、相对丰度、CLR 或其他变换；
- 多重检验校正方法与显著性阈值；
- 是否仅解释 Axis 1 / Axis 2，及其解释边界；
- 是否调整研究来源、批次、年龄、性别等协变量；
- 与 PCoA 稀有特征过滤集合和样本范围的绑定规则。

### 架构要求

该能力应拥有独立的分析策略、计算版本、API 产物和审计信息，不得由 React 对当前二维坐标临时计算相关性，也不得把相关系数命名为“PCoA loading”。

## 后端产物建议

后续不建议把所有内容继续堆入一个巨大图表 payload。可以在同一不可变投影身份下拆分为按需读取的解释性资源：

- PCA：`sample_scores`、`component_summary`、`feature_weights`、`feature_selection_audit`；
- PCoA：`sample_scores`、`dispersion_details`、`eigenvalue_diagnostics`、`feature_filter_audit`；
- 独立研究功能：`axis_feature_associations`。

解释性资源需要共享 `analysisRunId`、`artifactId`、`projectionKey`、`computeVersion`、样本范围摘要和参数摘要。默认图表仍可快速加载，用户展开表格时再按需读取对应资源。

## 前端信息结构建议

PCA：

1. 查看当前图表数据：样本坐标；
2. 查看主成分解释率；
3. 查看主成分贡献物种；
4. 查看筛选与合并明细：PCA 特征选择审计。

PCoA：

1. 查看当前图表数据：样本坐标；
2. 查看组内离散度：样本质心距离与分组摘要；
3. 查看特征值诊断；
4. 查看筛选与合并明细：PCoA 过滤审计。

这些入口可以复用统一的折叠区、分页表格和加载状态组件，但标题、列、解释文字和可用条件由图表注册配置决定，不在组件内按页面名称硬编码。

## 缓存与性能

- 第一批表格均来自当前 PCA / PCoA 计算过程中已经存在的中间结果，应在主计算时生成并随投影结果持久化，不在每次展开时重新拟合模型或重新计算距离矩阵。
- 大型明细继续使用服务端分页、筛选和排序；前端不得一次加载全部物种审计行。
- 投影身份变化后，旧解释性结果不得继续展示；前端应清空展开状态或重新请求。
- 解释性资源的生命周期沿用投影审计读模型：默认投影可长期复用，自定义投影按既定生命周期清理。

## 测试与验收

### 数值一致性

- PCA 样本坐标、解释率和特征权重来自同一个已拟合模型。
- 每个主成分的特征贡献率合计在数值误差范围内等于 100%。
- PCoA 质心距离与 PERMDISP 使用相同的全部正轴坐标。
- PCoA 轴解释率、正负特征值汇总与完整特征值序列一致。

### 身份与范围

- 切换全部样本、AD、NC 或自定义子集后，所有解释性表格与图中样本范围同步。
- 参数或过滤预设变化后不得复用旧表格。
- 单组范围不显示组间推断结论。

### 前端行为

- 折叠入口关闭时不预取大型明细。
- 表头在内部滚动容器中保持可见。
- 列名使用“样本”“物种”“主成分”等领域语义，不显示含糊的“项目 1”或“特征”。
- 加载、空结果、计算失败和投影身份过期具有明确且不同的状态提示。

## 推荐实施顺序

1. 扩展 PCA 计算产物：主成分解释率、特征权重、PCA 特征选择审计。
2. 重构 PCoA 组离散计算：在保持现有 PERMDISP 数值不变的前提下返回样本距离和分组摘要。
3. 扩展 PCoA 特征值诊断产物。
4. 为上述产物定义后端模型、OpenAPI 契约、分页读取和缓存版本。
5. 在前端注册 PCA / PCoA 专属解释性入口并补充交互测试。
6. 单独评审 PCoA 排序轴关联物种分析；方法获批后再制定实现计划。
