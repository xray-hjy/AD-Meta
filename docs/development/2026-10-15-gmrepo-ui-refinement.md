# GMrepo 证据工作页前端整理

日期：2026-10-15。范围：基于首版证据契约整理页面、交互和视觉层级；不修改来源数据、统计方法、纳排资格或科研解释权限。

## 对象评估

- 所选物种 / MAG / 参考菌属成为唯一主标题；移除装饰性英文眉题与模块介绍大区块。
- 分类对应、参考快照和属级用途直接可见。完整主版本、映射方法与原分析范围放入“对象与版本详情”；未解析原因不折叠隐藏。
- 工具栏优先提供可读报告；完整 JSON 放入次级导出。仍携带原对象、主/参考版本、run/artifact 与原可视化范围。
- 队列结果提前；概述保留服务端原始观察，不新增评分或推断。独立性与科研复核限制保持可见。
- 效应、区间、q 值和调整人数分栏；未调整与调整效应的单位不合并。暂缓检验保持空值而非补造数值。
- 选中队列与下方真实分布联动，保留原研究对象，滚动至分布区；遵循减少动态效果偏好。对象模式中不再重复出现可意外改变对象的菌属选择器，完整统计目录中的切换仍明确改变为参考菌属。
- 协变量核查、来源 marker 与主数据分类对照按需展开；暂缓检验的原因仍直接显示。原图表、样本散点、尺度切换、统计目录和所选队列 JSON 保留。

## 参考资源

- `/reference/gmrepo` 默认是可检索的研究目录，保留所有接入项目，不按显著性筛选；长核查说明改为行内展开。
- `section=quality` 展示原四类质量图、筛选、覆盖明细和样本核查；`section=methods` 展示官方发现范围、分页核对、API/TSV 差异、发现清单、流程及版本来源。
- 已有 cohort/group/scope/genus/page 深链接未指定 section 时仍进入质量视图；旧 `view=genus` 重定向继续保留。
- 视图切换保留筛选参数；重置只重置质量筛选，不返回研究目录。目录/方法视图不额外请求质量概览或样本表。

## 视觉与兼容

保留无侧栏全宽布局、内容顺序与三类资源视图。用户进一步明确要求“统一风格，不改布局”后，移除上一轮独立的白底文档视觉，复用主分析的深色渐变顶栏、灰蓝背景、白色圆角面板、标题色条、阴影、字体、表头和按钮/色盲开关状态。

公共主题位于 `frontend/src/styles/workspace-theme.css`：面板边框、圆角、阴影及标题背景抽为共享变量；主分析与证据页共同使用，证据页不再覆盖为另一套固定蓝色。顶栏直接复用 `app-topbar`、`app-title`、`topbar-home-link` 控件类。表格在移动端局部滚动，不压缩数值到不可读，也不造成整页横向溢出。

## 验证

相关前端回归 69 项通过，包含目录/质量/方法切换、原数据尺度与零值、固定版本、对象对应、队列选择和主分析入口。并行构建曾导致两个测试超时；限制为两个测试工作进程后完整复跑通过，没有放宽断言或测试时限。

浏览器脚本：`frontend/scripts/verify-evidence.mjs`。使用隔离 API 18100 和实际数据，在 `.tmp/gmrepo-evidence-qa/` 留存资源目录、质量、方法、对象页、移动端截图和当前 `verification.json`。最后执行结果应以文件中的 `status` 为准。

主题统一后最终执行：69 项相关前端回归、11 个真实浏览器场景通过，含 13 项目录检索、三类资源视图、首屏队列表、队列与分布联动、次级 JSON 下载、390px 无整页溢出、不可读版本失败路径，以及物种箱线图 / 完整结果行 / MAG 详情往返。JSON 下载件读回为 schemaVersion 1，参考属 NCBI:816，参考 fingerprint 与当前快照一致。前端 lint、类型检查和最新生产构建均通过。

新增实际计算样式对比：证据资源面板与主分析 chart-frame 的边框、16px 圆角、阴影一致，顶栏渐变、品牌文字颜色、主题蓝和字体栈一致；实际值记录在 `verification.json` 的 `visualTheme` 中。`main-analysis-style.png` 与 `species-evidence.png` 为同次执行的可视核查截图。

本轮不扩充 WGS、不认证跨研究独立性、不发布物种复现或模型验证结论。后续科研待办仍见首版实施记录及 SOP。

## 参考资源工作区联动改版

用户继续反馈资源目录孤立、页面结构不满意后，本轮进一步调整参考资源页，而非只更换皮肤：

- 资源页宽屏上限调整为 1880px，保留无侧栏及主分析主题；首屏合并研究项目数、Run、完整 profile，避免再增加一排无操作性的指标卡。
- 目录增加按全部 / 分布可用 / 队列内可检验 / 元数据与阶段参考筛选。默认保留全部 13 项，按可用范围及项目编号排列，不按效应或显著性排序。
- 项目行可就地展开研究说明、完整 profile、可用 AD/NC Run、来源和核查记录；“质量与样本”进入同一队列的真实原图表与样本表。无 AD/NC 子集的项目保留元数据，不展示伪造的 0/0 参与者或检验。
- 新增参考菌属目录：名称 / 旧名 / TaxID 检索、24 项分页、明确指定队列后进入证据分布。322 属是版本目录，不声称所选队列全部检出；没有可用 AD/NC 分布的队列禁止直接进入分布，可先核查质量。
- `referenceNavigation.js` 统一导航参数：资源视图间保留 subject、主/参考 revision、run/artifact、原图范围及 returnTo。只有明确选择参考菌属或退出对象上下文时才清除不兼容主对象字段；返回入口仍校验为本地分析路径。
- 资源页显示当前研究对象及继续评估入口；顶栏不再通过固定无参数链接丢失对象。无对象的导航进入可用菌属目录，旧无参数评估路径也显示完整检索目录。
- 目录搜索、可用性筛选、展开项目和菌属分页均写入 URL，往返时可恢复；质量筛选重置不再清空主对象。

后端 API、来源数据、统计方法和资格审查未改动。相关前端回归增至 74 项通过；实际浏览器验收增至 13 个场景，覆盖新工作流、2552px 宽屏、390px 资源页、对象跨页保持及原三个主分析入口。截图新增 `reference-wide.png`、`reference-study-detail.png`、`reference-genera-directory.png`、`reference-object-context.png`，最终状态仍以同目录 `verification.json` 为准。
