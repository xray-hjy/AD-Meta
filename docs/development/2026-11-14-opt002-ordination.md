# OPT-002：PCA / PCoA 筛选与绘图

本次为本地实现与验证，未发布服务器，未将飞书问题自动改为“已完成”。保留工作区此前的箱线图等改动。

## 已实现

- 两个页面均提供标准、全部物种、自定义、Top N、宽松、严格选项。保留 PCA Top 50 和 PCoA 标准的既有默认；是否统一新默认仍需生信负责人核对。
- 样本范围与物种条件需显式应用后重新计算。物种预览仅执行与计算相同的筛选、闭合及样本排除，不运行 SVD、距离分解或置换。
- 阈值以筛选前样本内闭合矩阵计算；源物种总丰度 > 0 的样本为检出率分母。最低丰度 > 0 时使用 ≥，为 0 时使用 > 0。Top N 按闭合后的平均相对丰度排序，名称用于稳定打破平局，筛选不使用标签。
- 显示源/保留物种、样本排除、平均与最低保留丰度；可展开筛选明细。预览请求取消及响应过期隔离，明细仅在展开时渲染。
- 颜色、点大小/透明度/形状、椭圆及线型、网格、图例、样本标签、标题、字号、图例位置、全图、缩放、平移、全屏与恢复样式。
- 使用同次计算中可用的前三轴组合，轴变换后使用相应坐标和组内分布椭圆，不重新拟合。PCA 近零解释率轴不作为可选轴。
- 每次完整重绘后恢复等单位坐标；X/Y 同步缩放；范围含样本及椭圆并留白。坐标轴固定外侧、精简浮点刻度，防止端点长小数被裁切。
- SVG / PNG 完整范围导出，可设尺寸；导出重算等比例布局。JSON 含选定轴坐标、筛选明细、预处理、方法版本、投影/数据版本/样本范围和参数。
- 沿用已有图框、工具栏与解释资源；PCA 载荷表仍保留。PCA 载荷箭头图层尚未增加，PCoA 不借用 PCA 载荷解释。

- 185 样本，1,828 种；种级总和 0.9999989–1.0000011，输入为原百分数除以 100 后的比例。
