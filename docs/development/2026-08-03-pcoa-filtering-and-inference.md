# PCoA 稀有特征过滤与探索性推断更新

## 变更原因

旧版 PCoA 按总丰度选择 Top 500 物种。这个规则便于控制计算量，但会把浏览器展示上限误当成距离分析的科学过滤条件，也无法说明被排除特征的生态学含义。本次更新把 PCoA 改为独立、可复现、可审计的数据准备管线。

## 当前计算管线

1. 按当前分析范围选择样本。
2. 校验丰度矩阵必须为有限、非负数值，并排除总丰度为零的样本。
3. 对完整特征矩阵执行样本内总和标准化（TSS closure）。
4. 使用不读取 AD/NC 标签的相对丰度与检出率规则筛选稀有特征。
5. 记录每个特征的检出样本数、检出率、平均/最大相对丰度、状态和原因。
6. 记录每个样本保留的丰度质量，并对保留矩阵再次执行样本内总和闭合。
7. 计算唯一的 Bray-Curtis 距离矩阵及 SHA-256 指纹。
8. PCoA 坐标、PERMANOVA 与 PERMDISP 共用这份距离矩阵；PERMDISP 使用该距离矩阵的全部正特征值坐标。

## 过滤预设

| 预设 | 单样本最低相对丰度 | 最低检出率 | 用途 |
| --- | ---: | ---: | --- |
| `unfiltered` | `> 0` | 不限制 | 敏感性检查，保留所有源特征 |
| `inclusive` | `0.001%` | `5%` | 宽松探索 |
| `standard` | `0.01%` | `10%` | 默认交互分析 |
| `robust` | `0.05%` | `20%` | 更强调稳定检出的探索 |

阈值是分析预设，不是浏览器 Top N。切换预设会产生不同的投影身份和缓存键，刷新页面或分享 URL 时仍能复现当前选择。

## 推断边界

只有当前范围同时包含两个分组，且每组至少 3 个有效样本时，系统才计算 PERMANOVA 和 PERMDISP。当前结果统一标记为 `computed_exploratory_unadjusted`，原因是现有 Manifest 尚未提供来源研究、批次、受试者重复测量或协变量，也未确认上游丰度尺度。

因此当前检验只适合探索性描述，不能声称已经完成研究分层置换或协变量校正。后续接入正式 Manifest 后，应在同一计算模块内扩展分层置换与设计矩阵，不在前端补做统计。

## 前后端契约

- 后端 `projection_policy.py` 声明 `filterPreset` 为选择型计算参数，PCoA 的 `topNRole` 为 `not_applicable`。
- 前端只展示四个离散预设，不允许任意输入阈值。
- 响应返回过滤规则、过滤前后特征数、保留丰度质量、样本排除情况、预处理步骤、推断状态和距离指纹。
- “查看筛选与合并明细”复用与投影相同的数据准备函数，避免图表和审计表采用两套过滤逻辑。
- 计算版本已提升，旧 Top 500 缓存不会被新策略复用。

## 验证要点

- 更换 AD/NC 标签不能改变入选特征。
- 过滤后的每个有效样本必须重新闭合为 1。
- 零总量样本必须明确排除并进入审计元数据。
- PCoA、PERMANOVA、PERMDISP 返回相同距离矩阵指纹。
- 无效预设必须由后端拒绝；字符串预设必须能通过 URL、会话状态、API 和缓存键完整往返。
