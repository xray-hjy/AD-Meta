# GMrepo 外部证据评估：完整交付方案

状态：已执行可由现有数据支撑的完整实现与验收，见 [交付记录](2026-10-17-gmrepo-complete-evidence-implementation.md)。新增来源条件不足时保留具体边界，不伪造合格队列或独立性认证。

基线：2026-10-17 收尾版本。已接入固定包 13 项、1,269 Run、800 完整 profile、322 属；5 个队列可展示分布、2 个具备当前队列内检验资格。来源登记共 18 项，58 项来源校验一致；已检索官方接口返回的 1,238 项描述，源端总数 1,349，另 111 项未返回。本方案不预设扩展后合格队列数或显著结果数量。

## 一轮交付目标

用户从主物种、MAG 或研究菌属出发，可以查看主队列结果、符合条件的外部队列结果、对应的实际样本分布、研究关系与适用限制，最后导出同一版本的完整评估。全部已发现来源具有明确处理去向，已接入数据能从原件重建、校验与复算。

本轮覆盖目录、全部既有/新增队列、主队列统计、关系评估、可视化、报告、交付包与部署检查。按依赖组织内部实施，整套完成后统一验收；不以单个队列或单张图完成作为本轮终点。

## 1. 目录与研究来源

- 查询官方表型目录、项目描述目录及可用下载/分页渠道，核对项目编号、源端总数与实取数，保留请求与原响应。尝试补齐未返回的项目身份；目前只有 111 的差额，没有完整编号清单，不能直接写成 111 项均已逐项筛查。
- 扩展检索的语境核查：AD、MCI、SCD、临床前 AD、认知下降及淀粉样蛋白相关研究均检查对象与阶段；泛指 preclinical 或其他疾病的描述保留排除依据。
- 核对项目、原论文、附录、作者数据、样本原库之间的关系。相关论文引用同一个 accession 不自动视为新的独立队列。
- 每项来源记录具体去向：可纳入 AD/NC、相关阶段参考、描述性数据、数据暂不可取得、资料不足或范围排除。相关但没有丰度的项目不能被记成范围排除。
- 取得失败须保留渠道、日期、响应/限制、缺少的字段及受影响用途；仅记录计数的范围缺口须保留为范围缺口，不能编造逐项目审查结果。

输出：更新的目录快照、来源文件、筛选记录与检索覆盖说明。

## 2. 全部队列的数据处理与资格

对既有 13 项固定包、5 项补充来源及本轮新增候选使用同一套检查。既有 3 个描述队列的参与者缺口和其他项目的分组冲突也纳入本轮补证，不能只检查新项目。

逐项核对：人群/疾病定义、样本材料、测序和处理、Run—标本—参与者—时间点对应、组别标签、对照来源、QC、丰度完整性、分类层级、原值单位及协变量。保留原标签、缺失原因和来源定位。

| 当前重点对象 | 本轮必须得到的处理结果 |
| --- | --- |
| PRJEB55056 | 获取并核对可用的元数据/丰度/原研究与附件，解释 72 Run 和 42 valid_runs 的差异，确定可支持 AD/NC、阶段参考或仅描述中的哪种用途；无可用数据时记录具体取得结果。 |
| PRJNA665245 | 核实纵向 WGS 的人、时间点、疾病状态及可取得丰度。若建立独立两组比较，按预先固定的基线/首次合格记录规则每人取一条并保留排除链；无法建立逐人关系时保留纵向描述范围。需要纵向模型的分析另以实际设计和数据条件决定，不能直接套独立两组检验。 |

满足条件的数据进入新的不可变处理版本。旧固定包、旧评估和旧主分析版本保留，禁止在旧目录内替换数据或沿用旧资格哈希。

输出：新处理包、统一样本表、特征表、原件/转换清单与逐用途资格结果。

## 3. 主队列属级结果与主外对照

### 主数据版本和派生语义

- 固定本项目当前发布的 MetaPhlAn 4 物种 revision、185 个 CRR 样本及 AD 122/NC 63 分组。纳入依据是研究 AD/NC 二分类并保留该项目两组全部样本。
- 按当前发布矩阵的明确属归属，汇总种级丰度生成独立的属级派生结果；不同时累加上层属行与下层种行。可用的原始 MetaPhlAn 属级行用于校验差异，不静默替代派生结果。
- 原百分数/比例换算保留版本语义，不重新闭合到共同命名属。未命名 GGB/SGB 和未可靠对应条目保留原标识及无法对照原因，不生成 NCBI TaxID。
- 统一方向、分类映射方法、缺失/零值语义、分析样本和检验族。匹配集用于对照展示，不用于事后缩小 FDR 校正范围。

### 统计与身份依据

- 原研究报告的人数与样本数支持本队列一人一份样本的解释；缺少公开逐人 ID 仍属于未完成的身份核验。主队列探索性计算明确采用原研究报告支持的观察设计及独立观测假设，不能把来源人数相同升级成已逐人验证。
- 全部符合预设规则的属使用固定分析集合；提供两组丰度/检出、方向、未调整秩效应及置信区间、p/q。固定种子及方法版本。
- 对可用的年龄/性别完整病例计算共同口径的调整模型，分别报告分母及不能估计的原因；核实后的批次信息可作敏感性分析，不把来源批次名称直接认作本项目技术批次。
- 主队列与外部队列分别在各自完整检验族内校正。校正集合和过滤规则在结果生成前固定，不按显著性删特征、删队列或更换方法。
- 相同定义的未调整秩效应可以并列展示，原始丰度保留各自量纲；调整效应与未调整效应分别展示。跨平台处理差异继续影响解释，不合并原丰度或伪装成统一实验。

输出：固定版本的主属级派生矩阵、完整统计、协变量/敏感性说明、主外分类对照表与未匹配清单。

## 4. 研究关系与证据解释

分别记录研究/论文复用、参与者对应、标本、实验/Run、时间点、家庭/配对设计及上游数据使用关系。单独说明队列内重复采样与跨队列重叠，不能互相替代。

证据用途逐项确定：描述分布、队列内探索性比较、主外同属结果对照、满足已核范围的独立外部评估。来源引用、原作者 marker、调整前后模型不重复计研究数；无重复公开编号不能证明参与者独立。

结果解释使用实际条件，如“本队列 AD 偏高，参考队列方向一致但区间较宽”“两队列方向不一致”“分类无法对应”“当前无法检验”。未显著与尚无数据分开；同向与通过 FDR 分开；不生成综合证据分数、独立支持票数或致病/保护结论。

输出：绑定版本与比较范围的关系记录、解释规则及对象评估结果。

## 5. 与现有可视化及研究流程贯通

沿用主分析的字体、配色、控件、图表工具与导出设置，保持同一个产品和全宽页面。

- 研究目录：可按人群阶段、平台、数据和使用范围查找，直接查看纳入/排除理由、样本范围和实际取得情况。
- 对象评估：先说明当前物种/MAG 如何对应到参考属，再并列主队列及外部队列的结果；对象和版本在目录、分布及主分析间保留。
- 未调整效应对照采用带区间的森林图，调整结果采用单独视图；保持当前队列箱线/样本散点、质量图、完整统计表和 WGS 分布的关联，图中选队列后查看相同范围的原始分布。
- 增加多候选结果表，允许从主分析完整结果选择候选集合，统一查看分类对应、可比较范围、方向及具体限制。默认 Top N 只控制展示，全部候选仍可检索和导出。
- 复用已经用于 MAG 的科研样式、缩放/视图复位、适用的框选、预览及 SVG/高清 PNG 导出；按图形实际交互语义适配，避免工具无效或影响统计集合。
- 16S 属级背景、WGS 物种/属级结果以及临床前阶段各保留来源与人群含义。KO、DiTing 通路暂不生成 GMrepo 功能证据；其当前可视化及主分析入口继续保持数据语义。功能外证需要另有真实功能矩阵和映射链。
- 用户页面呈现研究结果、来源和适用范围；不新增人员签署、待办清单或内外两个版本。

输出：完整对象流程、多候选对照、联动图表及同主题图像导出。

## 6. 快照、报告、复算与交付

同一次评估固定来源目录、参考包、主数据 revision、属级派生规则、分类映射、样本集合、协变量子集、检验族、模型版本、关系依据和结果。

页面、Markdown/JSON 报告、图像导出、完整统计及复算包使用同一 evaluationId。筛选和图形切换不改变统计分母；依赖变化标为历史，不用新值覆盖原报告。

扩展独立复算包以覆盖可分发/本地使用范围内的主属级派生结果、主/外统计及阶段描述结果。归档原件的哈希与来源；不能提供的原件说明获取条件，不能声称复算包重跑了未包含的 FASTQ 流程。新增参考包、来源归档及部署依赖需要一并检查，不能只在开发机目录存在时可用。

输出：版本化数据交付包、部署说明、完整评估导出、独立复算脚本与验收记录。

## 7. 统一验收

1. 目录：源端/实取数量可核对；返回的每个候选有去向；无法取得的范围及其影响明确，不伪造全库覆盖。
2. 数据：旧/新队列都按相同规则检查；样本映射、组别、重复记录、QC、零值/缺失、丰度和分类检查通过，资格随原件变化正确失效。
3. 统计：主外完整检验族、方向、区间、协变量分母与数值约定一致；检索、Top N、选择和分页不改变 p/q；恒定/稀疏/缺组/不能估计均有正确输出。
4. 解释：逐人验证、文献设计依据、编号重叠核对及跨队列独立性按各自范围呈现；阶段参考和重复采样不会被计成独立 AD/NC 验证。
5. 联动：单候选/多候选、主物种/MAG/参考属、目录/图表/报告之间的对象及版本保持一致，无映射不代入默认菌属。
6. 可视化：主分析同主题，图表工具实际可用；宽屏与移动端可读，图像与数据导出内容和当前评估一致。
7. 复现：实际下载后在独立目录复算主外统计，并读回冻结评估；旧评估及新环境部署按约定工作，正常入口能够访问。

本轮交付应同时给出已完成内容和仍受公开数据条件限制的具体条目。公开资料无法恢复的受试者身份、未返回目录或受限作者资料，属于已查明的证据边界；不以修改标签将其冒充已完成核验，也不因此搁置可完成的主外分析和产品功能。
