# MAG 热图聚类树与方法说明

## 已实现

- 热图下方常显当前样本和 MAG 排列方式、聚类输入、合并方法及距离口径。
- 聚类采用 SciPy 凝聚型层次聚类，average linkage、Euclidean 距离；输入为当前展示集合的 log10(1 + 丰度%)，可按已有设置逐 MAG 做 Z-score。
- 后端返回真实 linkage 合并记录及输入叶子 ID；前端据此绘制树枝，保留原有排序与单元格值。
- 样本组内聚类分别绘制 AD、NC 的树，共用样本树距离尺度，不连接两组。全样本聚类绘制共同树。
- MAG 聚类绘制行树；交换横纵轴时交换两类树的位置。缩放、平移及 SVG 导出保持叶子与单元格对应。
- 更多设置中的“聚类树”开关只控制树枝显示，不改变聚类排序。

## 使用

默认样本按疾病分组、批次和 ID 排列，MAG 保留选行排序，不执行聚类。选择样本组内或全样本聚类、MAG 聚类后，点击“应用设置”显示相应树状图。

## 验证

- 后端热图相关测试：13 项通过。

## 完整矩阵导出布局修正

原导出按每个单元格 20 × 22 像素扩展画布，导致数百个 MAG 的整图缩小显示时，固定字号和 80 像素深的聚类树几乎不可读。现改为矩阵自适应用户选择的标准 / 大图画布，标签、注释条、树深保持输出像素大小，依据实际空间疏排轴标签。全部矩阵值、合并分支、颜色范围、轴方向仍保留；PNG 使用 2× 输出，SVG 可无损缩放。

验证使用 872 个 MAG × 185 个样本：161,320 个单元格与 1,055 个合并分支完整保留，两个轴方向的 SVG 和实际 PNG 下载均检查通过。导出布局与图表相关测试共 23 项通过，ESLint、前端生产构建通过。新效果见 `docs/previews/mag-heatmap-export-fitted-transposed.png` 和 `mag-heatmap-export-download.png`。
