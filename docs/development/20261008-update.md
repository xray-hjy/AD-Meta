# 20261008更新

## MAG 页面与研究内容

- 统一 MAG 卡片、独立折叠区、轻量表头、搜索区和标题栏操作；折叠保留已选 MAG、分页和图表状态。
- 丰度图的排名、展示数量与列表分页 / 排序分开设置；单 MAG 分布结合箱线图、全部样本散点、统计与质量证据。
- 增加数据说明卡片和连续处理流程，展示 bins、CheckM2、质量筛选、dRep 去冗余与代表 MAG 的数量及方法来源。
- 丰富分类目录、质量散点、来源 / 去冗余、物种映射及技术质控的筛选、解释与数据下载。
- 建立研究扩展模板，标明已规划 / 待完成和缺失输入，不使用模拟结果代替未交付分析。

## 物种、KO 与共享图表

- 将 MAG 的原生 ECharts 条形图组件适配到物种丰度、门级组成、KO 丰度、KO 相对贡献和差异 KO 视图，保留各视图原有丰度、占比和 LDA 尺度。
- 增加单按钮柱线切换、原生柱体从零基线生长动画、分类 / 数值轴拖动条和区间浏览。
- 协调缩放工具、平移摇杆、全局预览、旋转标签及滑动轨道的位置，补充窄屏布局。
- 分组悬浮仅在柱体或数据点触发，保留同组强调与相邻柱组分隔线。
- 增加科研配色、双组配色、色盲辅助纹理、柱宽、圆角、标签精度、字号、网格和动画设置。
- 箱线图共享样式设置，保留原始箱体统计、离群点、散点和数据变换规则。

## MAG 热图与聚类

- 增加丰度概览、变化模式和候选对比选行；支持手动 MAG 清单、分类搜索、质量、阈值、统计候选等筛选。
- 展示数量面板支持全部匹配、常用数量、自定义输入、滑条、矩阵规模提示和显式应用。
- 完整矩阵支持连续缩放、平移、全局预览及横纵轴交换，保留原始样本 / MAG 对应和颜色范围。
- 采用 SciPy 凝聚型层次聚类，average linkage、Euclidean 距离；输入为 log10(1 + 丰度%) 或已选择的逐 MAG Z-score。
- 返回真实 linkage 合并记录与稳定叶子 ID，绘制样本树和 MAG 树；AD / NC 组内聚类分别成树，全样本聚类才显示共同树。
- 热图下方常显实际排列、聚类输入、合并方法、树枝距离和是否启用聚类，支持只隐藏树枝而保留排序。
- 修复完整热图导出在上万像素画布中压缩文字与树枝的问题：矩阵适配选定画布，标签按空间疏排、树深与字号保持可读，完整单元格和合并分支仍保留。

## 查询、数量面板与主题

- 新增 MAG ID / GTDB 分类名称自动补全，支持多字段候选、键盘操作、加载与空结果反馈。
- 使用 Base UI Select 替代普通原生下拉菜单，提供圆角、阴影、勾选、键盘选择、边界避让和主题继承。
- 物种蓝、功能青、MAG 玫红应用于菜单、浮层、按钮、滑动条和折叠标题栏。
- 物种、KO / 功能 Top N 增加预设、自定义整数、滑条、有效范围和显式应用；分别保留接口上限、显著结果数量及 PCA 特征重算语义。
- 浮层通过 Portal 与固定定位避免被卡片裁切，随滚动重新定位并支持 Escape 分层关闭。
