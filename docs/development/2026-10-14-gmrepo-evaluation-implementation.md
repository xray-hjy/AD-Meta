# GMrepo 外部证据评估模块首版实施记录

日期：2026-10-14，验收补充于 2026-10-15。依据[实施方案 v1.0](2026-10-14-gmrepo-evidence-workspace-design.md)和[SOP](2026-10-14-gmrepo-evidence-sop.md)。技术模块首版已实施；科研复核、扩展关键词筛选与独立性认证仍有明确待办。

后续研究台账、统一结构化资格、来源原件读回与 14 场景验收见[2026-10-15 迭代一实施记录](2026-10-15-gmrepo-research-ledger-implementation.md)；下文的首版测试数量与旧待办保留为历史记录。

## 已实施的产品闭环

2026-10-15 前端信息层级与资源视图进一步整理，当前页面结构见[证据工作页前端整理](2026-10-15-gmrepo-ui-refinement.md)；下文保留首版实施背景，数据与科研边界不变。

`/reference/gmrepo` 为外部证据评估的参考资源目录，新增规则、接入登记、来源文件可用性、官方发现范围和资格说明，保留全部现有质量图与样本查询。`/reference/gmrepo/evidence` 接收主对象，`/reference/gmrepo/evidence/:genusId` 直接查看固定参考属。

评估详情采用无侧栏全宽布局：研究对象与对应层级 → 规则生成的证据说明 → 全队列比较 → 原有分布/统计图 → 样本核查与来源。原参考页的 `view=genus` 深链接转到新页面；无对象时要求明确选择，不默认代入 Bacteroides。

主分析关联：

- 物种箱线图提供图中对象选择，固定稳定 ID、主 revision、run/artifact 和原范围进入评估，返回保留对象选择。
- 箱线图自定义特征选择池提供同一对象入口；未应用修改时先应用，避免丢失草稿。
- 完整物种结果表从特征行进入；`species` 结果类型与主数据 `taxonomy` 类型兼容，返回恢复查询、排序、分页和展开状态。
- MAG 分类详情使用固定 fingerprint 与已核对 crosswalk 的 NCBI 域/属路径；保留成员/代表关系，返回恢复主范围、视图和详情分类页签。缺路径时展示缺项，不猜测 GTDB 后缀。
- 顶栏和首页导航更新为“外部证据评估”；其他主工作区布局与既有科学图表操作保持原行为。

## 后端、契约和计算

新增 `/resources`、`/resolve-subject`、`/evidence-summary`、`/report` 只读接口，同步 OpenAPI 与前端类型。规则记录在 `backend/metadata/gmrepo_evidence_protocol.json`，正式科研复核仍为 pending。

解析器在固定发布物种 revision 内读取对象，并校验原分析产物；无法读取旧版本、对象不在产物内、分类域不符、缺少 MAG 路径分别返回状态。跨平台数值复现保持待核查。

汇总每队列各自的完整目标属检验结果，保留未调整/调整模型的不同单位和人数。来源 marker、两种模型不重复计研究数，不发布独立验证数量或合并 p/q。摘要每句有队列依据和规则版本。

队列统计增加有界缓存。缓存键包含输入、完整分类目录、样本/丰度、方法与最新审查结果；每次命中前仍验证身份依据。返回深拷贝，避免搜索/分页改坏完整 FDR 检验族。所选属 bootstrap 区间按实际数值与固定种子缓存。

支持完整证据 JSON 与 Markdown 报告，包含主/参考版本、来源范围、方法、队列资格及限制。原单队列图像和 JSON 导出继续可用。

## 真实来源清点结果

新增可重复运行的 `app.cli.inventory_gmrepo`。本轮实际访问官方网页公开脚本，核对其 POST API 与静态下载地址后获取原响应、时间、参数、文件大小和 SHA-256。原件保存于 `ADMetaData/reference/gmrepo/discovery/2026-10-14-v1`，版本化公开登记位于 `backend/metadata/gmrepo_discovery_registry.json`；原 2026-10-09-v1 丰度处理包未改写。

| 查询范围 | 源端 Run | 实取 Run | API 项目数 | 来源测序类型 |
| --- | --- | --- | --- | --- |
| Alzheimer Disease / D000544 | 798 | 798 | 13 | AMPLICON / Amplicon |
| Cognitive Dysfunction / D060825 | 215 | 215 | 3 | AMPLICON / Amplicon |

分页逐页去重并核对源端总数，两项均通过。本轮两个表型项目取并集为 14 项，AD API 的 13 项均在本地 13 项中；新增 PRJEB77146 来自认知障碍表型，登记为发现但未接入/待原研究审查，不能直接改成临床 AD 队列。

官方 AD 静态项目 TSV 仅列 8 项，API 列 13 项，静态缺少 PRJEB11419、PRJNA489760、PRJNA496408、PRJNA554111、PRJNA633959；两种原响应及差异一并保存。因此原来“当前 13 项可能只是少量 AD 队列”的担忧，至少在这次标准 AD 表型 API 的项目范围上得到澄清；不能进一步声称覆盖所有未标注或全部文献 AD 研究。

本轮已查询 Run 均标注扩增子，没有据此建立 WGS 接入。尝试使用官方项目选择器条件扩展关键词/WGS 发现时，服务返回 `1002 / Abnormal sql statement`，未计作检索完成，也未据此推断源库没有 AD/WGS。后续需要核实当前选择器的实际请求契约，再开展描述关键词和原研究交叉审查。此项与同研究对照、疾病阶段、材料和跨研究独立性复核共同保留为 partial。

源库返回的表型、论文标识与分组仍是待核对原值；新的发现登记不自动覆盖旧处理包中已核对的疾病阶段和原研究链接。源码发布保留轻量目录，完整原件仍属于单独科研归档；若迁移机器，需按登记恢复归档或执行新版本清点。

## 验证与案例

- GMrepo 后端科学语义、版本隔离、源文件、缓存失效、对象对应与安装器回归：37 项通过。Windows 下 ZipInfo 对反斜杠路径可能规范化，测试同时核对规范化后仍被精确文件白名单拒绝，不放宽安装器行为。
- GMrepo/新证据入口、完整结果、MAG 工作区、首页和分析范围相关前端回归：67 项通过，含固定结果行对象/版本/产物链接及专用查询超时回归。API 类型检查、前端 lint、目标后端 Ruff/mypy 和生产构建已核验。
- 真实包读回：13 项、1269 Run、800 完整 profile、322 属、5 分布队列、2 个现有检验合格队列。
- 隔离验收使用 18100 API，禁用启动迁移，读取实际主数据库与参考包；没有重启用户的开发服务或重建主数据。
- 浏览器检查真实资源目录、无侧栏评估页、保留的分布图、390px 无整页横向溢出和不可读主版本的失败路径。
- 真实主物种案例：ID 1937 / Bacteroides uniformis，主 revision `2005c6a7f1554cebbb47632c81fe3bcb`，对应外部 Bacteroides / NCBI:816；从原箱线图进入评估再返回，研究对象恢复。
- 完整结果原始 300 行查询本次实测约 17 秒，超过通用 15 秒超时；仅此查询调整为有界 60 秒等待，保留 signal 取消和显式错误，不修改数据、SQL 或其他接口时限。全表结果行往返、搜索 1937 后进入同一固定物种评估、返回恢复搜索条件及展开区域均通过真实浏览器验收。
- 真实 MAG 案例：CRR1012739__CRR1012739_cleanbin_000002，当前固定 MAG fingerprint 的 NCBI 路径对应 Phocaeicola / NCBI:909656；详情进入评估并返回恢复分类页签。该关联仅为属级背景。

验收脚本为 `frontend/scripts/verify-evidence.mjs`，输出到 `.tmp/gmrepo-evidence-qa/`：真实 JSON/Markdown 案例、桌面/移动截图、`verification.json`。2026-10-15 最后一次执行状态为 `passed`，7 项浏览器场景通过且无页面运行错误。脚本每次开始覆盖状态为 `running`，异常写为 `failed`，避免旧成功记录掩盖本次失败；失败时留存完整结果 DOM 与截图。这些是实际执行产物，示意数据不计入真实案例。

## 使用与复查

正常启动后，首页/分析顶栏进入“外部证据评估”，或从主物种箱线图、完整结果行、MAG 分类详情直接进入。返回按钮恢复原分析上下文。

完整来源清点需网络访问，生成新版本目录：

```powershell
node scripts/backend-python.mjs -m app.cli.inventory_gmrepo --output ADMetaData/reference/gmrepo/discovery/<新版本目录> --publish
```

浏览器验收需启动独立 API，避免启动迁移；以下端口仅供本任务验收：

```powershell
node scripts/backend-python.mjs -m uvicorn app.main:app --host 127.0.0.1 --port 18100 --lifespan off
node frontend/scripts/verify-evidence.mjs
```

持续待办：完整关键词范围、发现项目的材料/阶段/对照审查、跨研究与主外独立性认证、主矩阵单位与生成口径、科研人员复核、真实 WGS/功能/模型结果就绪后的扩展。它们影响科学解释权限，页面中明确体现，技术首版不替代这些结论。
