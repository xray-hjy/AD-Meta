# MAG 丰度与单 MAG 分布优化记录

## 本轮范围

落实共享条形图、共享箱线图、图表与结果列表分页分离、所选 MAG 固定和单 MAG 证据摘要。差异概览及候选筛选的默认阈值作为后续扩展，未在本轮增加。

## 分析与交互口径

- 丰度图用于观察当前样本范围内丰度较高的 MAG 及 AD / NC 组均值，不把高丰度等同于显著差异或已验证候选。
- 图表独立请求 offset=0、limit=Top N（10/20/30/50），按全部所选样本、AD 或 NC 均值降序选取；默认全部所选样本均值 Top 20。
- 列表独立请求分页和排序；MAG ID 搜索同时限定图表及列表的对象范围。列表换页或按 q 值排序不会替换图表对象。
- 图表输入是上游 MAG 相对丰度百分比，未闭合至 100%，未对所选 Top N 再归一化。空组保持缺失值。
- 点击条形或列表 MAG ID 打开该 MAG 的分布。候选页、搜索、样本范围变化不会自动换掉所选 MAG。
- 单 MAG 箱体和 1.5×IQR 须直接使用后端统计；叠加当前范围全部样本，包括零丰度。横向散点偏移按样本 ID 固定，不改变丰度坐标。
- 丰度阈值仍采用严格大于，仅影响阈值比例及数量统计；Mann–Whitney U、BH-FDR 和秩效应量计算未改变，仍未做协变量校正。
- 分类和质量通过稳定 MAG ID 关联，分类名称回退至实际已解析层级；缺失注释不填造数据。
- MAG 功能注释状态为“待完成”。单 MAG 来源按钮以该 ID 预筛选聚类、crosswalk 并打开证据链。

## 组件结构

`GroupedBarChart`：共享分组横向条形图、圆角、动画、轴、提示与点击事件。门级组成、KO 相对贡献和 MAG 通过配置传入各自数值尺度、标签、条宽和间距。MAG 使用 11px 细条、浅色提示和虚线轴指示。

`BoxScatterChart`：共享箱体、散点、提示和坐标轴。物种保留多特征布局、原有变换与离群点；MAG 使用 AD / NC 两组布局、原始百分比、宽箱体及全部样本散点。

业务查询与数据转换保留在各业务组件，绘图使用 React 组件组合与参数配置。

## 导出及可复现性

- 图像导出使用图表独立选取的数据，文件名记录排名字段、Top N 和搜索范围。
- 完整候选 CSV 不被图表 Top N 或列表页截断，保留所选样本范围、搜索及列表排序。
- 分析溯源 JSON 同时记录列表 pageOffset/pageLimit/sortBy/direction 和图表 chartSortBy/topN/displayedMagIds。
- 分类字典在 CSV 中以 JSON 字符串输出。OpenAPI 及前端生成类型同步新增分类、完整度与污染率字段。
