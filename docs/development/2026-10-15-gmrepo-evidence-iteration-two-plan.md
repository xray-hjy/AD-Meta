# GMrepo 外部证据评估：迭代二实施方案

日期：2026-10-15。版本：1.2。状态：用户已确认执行；首批来源样板、有效复核技术链、对象解释与固定记录读回已实施，扩展来源、人工科研复核和完整可重算发布包未全部完成。进展见[迭代二实施记录](2026-10-15-gmrepo-iteration-two-implementation.md)。本方案制定当次仅做只读核对，后续执行未改写原运行包或统计方法。

接续[总体方案 v1.1](2026-10-15-gmrepo-evidence-next-iteration-plan.md)和[迭代一实施记录](2026-10-15-gmrepo-research-ledger-implementation.md)。v1.1 继续作为范围约束；本文细化下一轮，不把上一轮已经交付的台账、页面联动和图表重新列为待建设。

## 1. 本轮决策

下一轮目标：**让已经建成的台账具备真实研究内容，让待补事项可以被有效处理，让某次评估能够按当时版本重新读取和核查。**

近期优先级为：研究资料核实与来源补齐 → 有效复核和证据引用闭环 → 对象级解释 → 固定评估与交付包。资料整理与底层契约开发可并行；解释和发布只消费已核实到对应程度的记录。

不再重做全页布局，不增加侧栏仪表盘，不用更多统一 pending 文案代替资料工作。不以增加可检验队列数、显著性数量或必须找到 WGS 为目标。

## 2. 当前基线与实际缺口

本次离线读回：14 项登记、13 项接入、1269 Run、800 完整 profile、322 属；5 个分布队列、2 个具备当前未调整/调整检验资格。9 份现有发现归档原件大小和哈希一致。来源范围仍为 partial，科研复核仍为 pending。这里的 9 份指发现清点归档，**不是全部论文、历史原件与上游材料已经补齐**。

现有主物种数值对照仍受单位/标准化、参与者关系、分类与方法可比性限制。本轮不因补齐研究名称或找到论文而解除它。

## 4. 2A：先给台账补真实研究内容

### 4.1 先做小批样板，再覆盖全部登记

第一批为 PRJEB51982、PRJEB59009、PRJEB77146：

- 前两项沿用现有专项身份依据，核对如何从原研究得到材料、疾病阶段、样本和参与者信息，建立正确的字段引用样板；不重复宣布已经完成全面科研复核。
- PRJEB77146 代表“仅发现、未接入”路径。核对是否属于目标人群/材料、如何定义认知阶段、是否有同研究对照和可取得的数据。结论可以是继续获取、仅阶段参考、明确不纳入或无法确认；不预设一定接入。

第二批处理 3 个有分布但检验暂缓的项目：PRJNA554111、PRJNA633959、PRJNA770746。逐项判定真实阻断原因，不能保证补资料后都能开放检验。

第三批覆盖剩余 8 项元数据/阶段参考项目。按同一口径登记原因与证据，不因为不符合当前 AD/NC 比较就从资源发现清单中消失。

上述顺序只按现有能力与代表路径安排，不按显著性挑研究。首批结束即可验收样板，不要求等待 14 项所有未知字段都得到答案。

### 4.2 每项研究的最小资料包

保留 project accession，并在有依据时关联原研究；一个原研究可能有多个项目或论文，同一项目也可能含多个阶段/比较。无法确定关系时保持未知，不为凑数自动合并或拆分。

逐项整理：原研究/论文标识及关系；研究名称/年份；人群与地域；人体材料；AD、NC、MCI、风险/临床前定义；平台与分类方法；研究设计/采样时间点；样本与参与者对应；比较分组及协变量；获取和纳排状态。

每个关键事实分别记录原值、整理值、来源对象与页/表/字段/样本定位、整理日期和核查程度。资料整理可以形成“有来源、待科研复核”的值，但不能由抓取成功自动变成“已通过”。来源冲突并列保留，已有有效专项依据不被新抓取的未核查文字覆盖。

对每项发现给一个可对账的主要处理去向：待筛查、符合参考范围待获取、可用参考、仅阶段参考、不符合本次范围、资料不足无法判断。数据是否已安装另列，不与纳排混为一个状态。排除必须有原因及依据；未取到文件不等于研究不存在。

### 4.3 检索与获取的具体安排

1. 保存回顾性检索口径：人体肠道/粪便、AD/同研究 NC；相关阶段单列；16S/WGS 分开；不按显著性选择。其他材料/动物研究可保留发现记录，但不纳入当前人体肠道比较。
2. 实施时核对官方当前公开请求契约，优先复用既有表型 API、完整分页和官方导出，再补项目描述与相关关键词；不能在未核对接口时承诺某个关键词端点可用。
3. 对现有论文候选核实项目关联，可利用原研究、作者公开补充资料及 ENA/NCBI 记录交叉定位；不能仅因主题相近就认定是该项目的原论文。
4. 每个新批次保留 URL、请求参数、时间、响应/错误、字节数、哈希和归档路径；区分“HTTP 成功”“来源返回错误”“格式有效”“分页核对完成”。选择器错误 1002 仍记作未完成范围，不记作零结果。
5. 获取/格式/分页失败时保存本批诊断，不把不完整候选清单直接覆盖当前有效发现索引。先产生候选索引与增删/标签差异，再进行明确的发布动作；旧索引和归档可恢复。
6. WGS 输出实际搜索范围、发现/未取得/待核查/无合格记录的结果。只有指定范围检索确实完成时才可写该范围没有合格记录，不能外推全库没有 AD/WGS。

对 9 份现有发现归档完成读回，不等于解决旧处理快照全部获取回执缺口；后者另列清单，并检查取得/再分发权限。本轮不自动下载大型原始测序数据或启动 WGS 重处理流水线。

## 5. 2B：让复核和待办真正形成闭环

### 5.1 最小契约扩展，不重建审核后台

复用现有 metadata、manifest 和受管产物存储，优先文件登记 + 校验 CLI；不引入账号系统、任务分派平台或复杂数据库图谱。

需要明确类型与引用的对象：

- EvidenceSource：来源 URL/归档对象、哈希与大小、获取日期、可读取状态、具体定位。字段和审查引用 sourceId，而非只有不可校验的路径字符串。
- StudyLink / Comparison：项目与原研究关系、比较类型/阶段、材料和设计、观察单位、样本/参与者关系、各模型实际范围和内容指纹。Run 集合哈希只证明编号集合，不能替代分组、协变量和处理内容校验。
- Review：用途、字段或比较范围、输入/方法版本、依据指纹、真实复核者/角色与日期、意见、决定、supersedes。资料整理、科研方法、技术发布三个职责分别标明。
- IssueResolution：问题状态、处理说明、对应依据和生效审查；“记录了下一步”不等于问题已解决。

输入 schema 采用版本化兼容迁移；旧登记缺新字段时明确未提供，不能推断已通过。API 增量扩展并同步 OpenAPI/前端类型，旧版本链接保留。

### 5.2 有效状态与更正规则

按“项目/研究 + 比较或字段 + 用途 + 固定输入/方法范围”计算有效审查，不以文件中的最后一条记录自动生效。更正必须明确引用被替代记录；禁止跨版本/跨用途替代、循环引用和相互冲突的多条当前决定。冲突或依据不可校验时保持待处理/暂缓。

历史撤销不删除。有效恢复记录可以在相同范围经复核后替代旧暂缓，但不能简单追加一个 confirmed 就消除全部门槛。旧报告保留当时状态，并能看到后续撤销/更正提示；重新计算必须生成新评估版本。

肯定意见只影响其审核用途：

- 字段核查通过，只更新该字段状态；不能自动开放检验。
- 身份核查通过，还需分组、设计、样本量与模型条件满足，才可能开放相应队列内方法。
- 科研复核通过，只能覆盖明确的方法/解释/版本范围；不自动代表研究独立性或主外可比性通过。
- 重叠审查需说明研究间/主外、核查范围、资料充分度及结果；发现复用、限定范围未发现复用、信息不足分别报告。“未发现相同 Run”不能单独支持独立复现。

因此不是把当前固定 pending 一律改绿，而是使每项状态具备可核实的转换条件。复核人员未指定时保持待复核，开发者或测试脚本不得代填真实批准。

### 5.3 来源边界和校验补强

发现清单的参考 fingerprint 缺失、错误或格式无效时，不把其项目/范围当作当前固定版本的已确认发现；显示未知/不匹配并保留诊断。其他参考版本的审查不得直接授权或撤销本版本；本版本需要的撤销/复核登记不可验证时不应自动沿用资格。

来源文件哈希/大小、定位、审查范围和依赖关系均需验证。缺原件与证据失效分别报告；涉及资格的依据失效应使结果用途受限。恢复可读不等于科学审查通过。

## 6. 2C：让对象页解释实际研究问题

沿用现有全宽页面和图表。阅读顺序保持：主对象与对应层级 → 当前可作何种解释 → 各队列结果 → 所选队列依据与原分布 → 方法/完整审计。

默认展示与当前对象相关的事实和阻断；完整台账仍可下钻。共有的独立性/复核限制可以统一说明，项目特有的分组、身份、材料或平台冲突必须单列，避免每个队列重复同一段通用待办。

新增结构化解释条目，至少绑定：claimId、规则版本、主/参考对象版本、项目/比较、统计字段、样本范围、来源/复核引用。解释由确定性规则生成；同一对象、同一冻结输入应有相同科学含义。

需要覆盖的表达：

- 属级对应成功/无法对应，与主物种或 MAG 的解释层级。
- 描述性分布可用但检验暂缓，明确不能据其分布方向宣称统计关联。
- 有资格时分别列未调整和调整结果、效应单位、完整病例范围与 q 值；方向不一致和模型不可估计如实说明。
- 未获 FDR 支持不写成“没有关联”；不把全零属、未检验、不可估计混成“无明确方向”。
- 来源 LDA 与本项目重算分开，混合阶段来源 marker 不当作纯 AD/NC 证据；模型、来源记录和项目数不重复计作独立研究。
- 主物种矩阵有分类覆盖但不可作数值对照时，说明具体缺项；对 MAG 不用物种矩阵覆盖冒充 MAG 丰度复现。

当前不同层级/单位的效应不共用可相加的比较轴，不新增自动证据总分、推荐等级或跨研究合并 p/q。

## 7. 2D：固定评估、导出和最小交付包

### 7.1 同一次评估共用一个版本

评估快照建议绑定：主对象/主 revision 及 run/artifact、参考 fingerprint、发现清单和台账指纹、有效审查与证据依赖、比较集合和内容、分类映射、方法/规则/相关代码与依赖环境、完整结果及解释条目。

用确定性内容摘要生成 evaluationId；生成时间另列，不能因重复下载改时间而变成另一份科学评估。原图选择/查询/返回上下文作为明确的来源上下文保存，不改变外部比较分母。无需先为所有候选生成快照，按需生成/冻结即可。

页面、JSON 和 Markdown 应消费同一个快照，而非三个入口各自再算一遍最新状态。登记更新后可生成新评估，并提示旧评估依赖变化；历史查看保持原内容和历史用途限制，不静默替换为最新结果。涉及后续撤销的快照不能继续展示为当前仍有效。

API 可增量支持 evaluationId；老链接默认计算当前评估并明确版本。复用现有受管产物机制；具体存储接点实施时以当前代码为准，不把历史设计稿中的未落地组件当作现成能力。

### 7.2 最小可核查包

包括冻结清单、来源/证据索引、研究与比较登记、有效及历史审查、相关规则/方法/代码摘要、完整计算结果、解释条目、JSON/Markdown 和校验报告。使用相对受管引用及实际可取得的依赖，区分运行所需文件与可重处理科研归档。

不要求复制整个主数据库或全部科学原件；未随包提供的依赖须标明获取位置、权限和缺项。不得自动公开参与者敏感资料或无权再分发的原件。校验结果分别说明：可独立读回、可重新计算、只可追溯但缺依赖。

至少采用预先按路径选取的真实案例：物种 1937 的属级背景、可靠 MAG 对应或缺路径、一个资格不足的队列。若实际存在方向冲突或未获支持结果，再按公开选取规则补充；不保证出现显著支持。

存储结果的完整性可做精确哈希；跨环境重算使用事先说明的浮点容差和不变条件，不能把任意环境下逐字节一致作为未验证承诺。

## 8. 验收与停止条件

| 验收范围 | 必须满足 |
| --- | --- |
| 研究资料 | 首批 3 项有可定位的样板；14 项均有实际筛查/处理去向、已知字段和具体缺项，不要求强行填满未知值 |
| 来源检索 | 新批次的查询/错误和未完成范围可对账；响应错误、格式错和分页不足不会覆盖当前有效目录；不因找到零新增就宣称全库完整 |
| 审查状态 | 人工真实决定、有效范围、引用校验、更正链和撤销传播可测；未知不升级；单一用途通过不跨用途放行 |
| 科学计算 | 不改变当前方法和完整 322 属 FDR；筛选/分页/选属不改变 q 值；缺 profile 不补零；不同模型集合和单位明确 |
| 对象解释 | 每条解释能追到对象、结果字段、范围和规则；覆盖无法对应、无检验、不可估计、方向冲突和未获支持，不用示意结果冒充真实案例 |
| 快照/报告 | 页面与两种导出同一 evaluationId；新记录不篡改历史快照；失效依赖有提示并限制当前用途 |
| 交付读回 | 独立读取冻结包验证引用、数量、哈希和已声明的可重算范围；不只比较同一函数产生的两份状态 |

## 9. 条件化后续与项目侧输入

主矩阵语义核查可以并行形成材料，但数值对照的计算仍需单位/归一化、分类聚合、参与者/重复关系、主外重叠与方法条件。可比性和独立性是两道门；任一通过都不自动证明物种/MAG/功能复现。WGS、KO/AMP 归属和冻结模型外部验证继续作为独立扩展，不占用本轮必达承诺。

技术和公开来源整理可先做。肯定的科研决定需要项目提供实际复核人员/职责、无法公开取得的原件或样本对应、必要时的方法意见。未提供时不阻塞其他可做工作，但保持相关用途待复核。
