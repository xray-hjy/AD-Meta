# MAG 丰度对比接入 ECharts 原生交互

## 参考与范围

参考用户提供的 Apache ECharts `bar-large` 预算对比示例：

- [官方示例](https://echarts.apache.org/examples/en/editor.html?c=bar-large)
- [官方 toolbox 定义](https://github.com/apache/echarts-doc/blob/master/en/option/component/toolbox.md)
- 本项目已安装 ECharts 6.1；对照安装包中的 `MagicType`、`SliderZoomView`、`InsideZoomView` 实现核对行为。

本次替换 MAG 丰度对比的自绘柱体、折线、坐标轴、图例及区间滑动条。后端查询、百分比口径、排名、Top N / 全部 MAG 选择、统计检验和结果列表不变。其他可视化继续使用原有适配器。

## 对应实现

| 官方示例能力 | MAG 适配 |
| --- | --- |
| 两个 `bar` 系列 | AD / NC 原始平均相对丰度；零仍为零，未提供仍为 null |
| `legend` | 原生可点击图例，同时提供键盘按钮；显示状态用于完整导出 |
| `magicType` | 保留工具栏切换按钮，调用官方 `changeMagicType` action；MAG 在横轴时提供折线 |
| 分类 `dataZoom.slider` | 原生底部拖动选区和手柄，控制当前 MAG 浏览区间 |
| 分类 `dataZoom.inside` | Alt + 滚轮缩放；普通滚轮用于页面滚动 |
| 数值 `dataZoom.slider` | 右侧范围拖动条，使用 `filterMode: empty` 保持 MAG 类别位置；更多设置可关闭 |
| tooltip / axisPointer | 适应既有“只进入柱体 / 数据点触发”需求，使用 item tooltip 与 series emphasis；不在整个空白区域识别分组 |
| dataView | 工具栏打开只读、分页的现有表格组件，显示当前完整图表集合，不允许修改科研原始值 |
| restore | 官方恢复 action + 共享相机恢复完整区间；保留用户选择的样式 |
| saveAsImage | 继续使用现有 SVG / PNG 完整集合导出、原始 MAG ID 与参数文件名，不导出导航面板 |

`mark`、`calculable` 是示例中的历史配置，未作为当前 ECharts 6 新功能接入。预算 JSON、jQuery 数据读取、预算单位及固定 94%–100% 初始区间均替换为项目自己的数据与状态。

## 共享导航及保留功能

- `NativeGroupedBarSurface` 在同一个 ECharts 实例上绘制，换方向 / 换图形不会卸载共享视口。
- 分类 dataZoom 百分比与 `ZoomableChartViewport` 的可见 MAG 区间双向同步。程序同步使用 silent action，用户操作在动画帧合并，避免反馈循环。
- 摇杆、全局预览、缩放比例、适应宽度 / 全图 / 原始大小、键盘平移以及 Alt 拖动继续使用同一相机。
- 原生 inside 处理滚轮，D3 不重复处理；D3 保留图内拖动。
- 分组标记使用公开 `convertToPixel` 定位的轻量 SVG 注记，保留柱组之间虚线与 AD / NC 名称；密集区间隐藏注记。分组悬浮和分组标记仍为独立开关。
- 标签使用原生 truncate / hideOverlap，数值轴按当前分类区间和可见系列计算范围，绘制 872 个 MAG 时关闭密集数值标签和折线符号。
- 拖动时通过短 dataZoom action 更新，只有标签密度变化时补发系列样式；不在每一帧重新提交完整数据数组。
- MAG 主题色用于原生滑动条。色盲辅助纹理、圆角、柱宽、小数位、字号、网格、图例、动画及横纵轴切换保留。

## 原生动画适配

依据 [ECharts 数据过渡说明](https://echarts.apache.org/handbook/en/how-to/animation/transition/) 补全动画：

- 更新使用合并模式与稳定的系列 / MAG 数据 ID，保留引擎的前后状态进行差异过渡；不再通过 `notMerge: true` 重建图表。
- 入场采用官方示例默认的 1000 ms / `cubicInOut`，没有逐柱延迟。由原生 `BarView` 将新柱体的高度 / 宽度初始化为零：竖向从底部向上长，横向从零基线向右长。常规数据 / 排名、图例更新采用 320 ms。
- 柱线切换仅执行一次官方 `changeMagicType` action，禁用 `universalTransition` 形状变换，保证折线切回柱形是从零高度生长，而非满高度矩形参与变形；避免紧接着重复 `setOption` 中断动画。
- 图表首次可见、重新展开、切换柱形轴方向时重放原生入场。实际视口尺寸确定后才开始，防止初始测量的 resize 中断；隐藏时清除旧帧，避免展开瞬间闪出满高度柱体。相机区间、数值缩放范围、图例选择和样式从现有状态恢复。
- 坐标轴与缩放目标显式替换 / 清空，防止换方向后旧轴配置残留。
- 共享相机平移使用 80 ms 的原生 action 过渡；原生滑动条 / inside 使用引擎自身的短过渡，不在导航每一帧上传全部数据。
- 当前视野超过 400 个 MAG 时关闭大规模图形动画；浏览区间缩小后恢复，并设置引擎 `animationThreshold`。此阈值针对可见工作量，不按目录总数永久关闭。
- 工具栏的“动画”开关控制所有过渡；系统启用减少动态效果时同样关闭。完整静态导出继续使用最终状态。
- 浏览器验证不仅检查“动画在运行”：逐帧读取实际画布像素，在首次展开、折线切回柱形、重新展开中，AD 柱从约 1–4 px 长至约 429 px，存在中间高度，且零基线始终固定。关闭开关时直接完成，全部 872 个 MAG 简化动画，窄区间恢复。原生滑动条、悬浮、共享导航及 SVG 导出回归通过。

## 2026-10-07 导航布局与滑动条

- 底部分类滑动条与绘图区共享 `left / width`，右侧数值滑动条共享 `top / height`。保留旋转标签与底部说明的空间，右侧预留轨道、原生拖动柄及导航面板之间的间距。

### 2026-10-07 工具栏简化与导出设置

- 柱状 / 折线使用一个切换按钮，当前图形名称和图标随状态更新；图标交叉淡入，画布短淡入衔接原生柱体生长与折线过渡。动画开关和系统减少动态效果仍生效。
- 删除工具栏“查看图表数据”动作；底部已有的只读数据折叠栏保留。
- 导出改为带下载图标的主题圆角按钮。MAG 丰度面板提供 SVG / PNG、自动 / 标准 / 大图 / 自定义尺寸、PNG 1×–4× 像素倍率及实际输出尺寸说明；默认设置存储在浏览器，支持保存和恢复。SVG 不使用像素分辨率。
- 导出参数传递到原有完整集合导出逻辑，保留全部 MAG、图例选择、主题和分组注记；PNG 大图沿用像素边长与总像素适配。其他 MAG 图形继续使用原有导出参数。
- 基本检查：13 项已有组件测试及 ESLint 通过；浏览器单按钮双向切换、删除数据按钮、默认设置保存 / 重开、800 × 500 的 2× PNG 实际下载为 1600 × 1000，未出现页面错误。

### 自定义 Top N 面板

- “显示”改为主题弹出面板：常用 10 / 20 / 30 / 50 / 100 / 200、整数输入、滑条、“全部匹配”和推荐数量。上限为当前搜索匹配数；修改草稿不触发查询，点击“应用”或回车后提交。
- 图表选取仍独立于列表分页和列表排序。超过接口单页 300 个时，分批读取前 N 个；保留搜索、排名、样本范围及取消信号，核查各页版本一致和 ID 完整。
- 基本验证：自定义 365 个、全部 872 个、非法数量禁用应用、草稿不重绘均通过；分批读取单测和既有分页独立性检查通过。

- 适配器单测覆盖双向区间、原始 ID、百分比 / null、原生 action、图例、分组标记、只读表格、完整导出及销毁清理。
- 浏览器实际操作：柱体悬浮 / 空白清除 / 关闭悬浮；横纵轴与柱线切换；底部原生选区拖动；独立数值轴范围；SVG 下载；全部 872 个 MAG；760 px 页面。

## 2026-10-07：物种与 KO 的条形图定向接入

- 实际接入 5 个页面入口：物种丰度、门级组成、KO 丰度、KO 相对贡献、KO 差异特征效应。前两种原始丰度入口共享 BarChart，因此共涉及 4 个页面适配组件。
- 复用 ZoomableGroupedBarChart / NativeGroupedBarSurface 的原生 ECharts 渲染、动画、分类/数值区间、共享摇杆与预览、样式工具栏、柱体悬浮、图例及只读数据表。导出设置提取为 ChartImageExportSettings / ChartExportMenu；MAG 保留原有导出默认设置的存储键。
- 原始物种/KO 丰度不转为百分比；零、缺失与极小值分别保留。完整物种分类和 KO 名称继续用于悬浮提示。物种默认竖向，可切换横向；分类及相对贡献默认横向。
- 门级组成固定 0–1 原始比例域，轴/标签按百分比显示；KO 相对贡献保留样本内归一化后组均值、覆盖比例和未合并为 Other 的说明。百分比只读表按显示单位转换，避免将 0.45 标为 0.45%。
- KO 效应图使用互斥的 AD/NC 稀疏序列重叠在同一分类位置，每个 KO 仍只有一根效应柱；零线、对称数值范围、负值左端标签、p/q/log2FC 与两组均值保留，p=0 不回填为 1。不开放折线或横竖互换，以保留富集方向表达。
- 主题从所在工作区继承：物种蓝色、KO 青绿色、MAG 玫瑰色。各入口样式偏好独立。已有 Top N 查询策略和统计筛选仍由分析策略层控制。
- 图表数据表通过 ChartSupplement 保持独立于主图折叠；分类标记 SVG 使用实例唯一裁剪 ID，避免多个实例相互影响。

验证：32 个相关组件测试通过；改动文件 ESLint 通过；生产构建通过。真实页面检查了前 4 个入口的渲染、比例/单位、切换、区间导航、SVG/PNG 导出、折叠及窄屏，未出现浏览器错误。原 MAG 的单按钮切换、PNG 1600×1000 输出和默认设置回读通过。

当前真实 KO 数据默认 q<0.05 时没有通过 BH-FDR 的特征，保持原有空结果提示。效应图渲染与左右方向另以浏览器请求拦截的明确 QA 测试数据验证，测试数据未写入项目数据或后端。该截图仅存 .tmp；docs/previews 的物种/KO 图像使用真实数据。
