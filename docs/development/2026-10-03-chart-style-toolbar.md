# 条形图图形样式工具栏

## 组件结构

- `ChartStyleToolbar.jsx`：通用圆角毛玻璃容器、开关、选择框、更多设置、重置，以及 Escape、点击外部关闭和焦点返回。接收 `fields / values / onChange / onReset`，不包含任何数据分析逻辑。
- `BarStyleToolbar.jsx`：条形图专属设置项和适用能力；根据原图配置显示默认开关状态。整数数量图不开放小数位，未配置图例的图不开放图例开关。
- `barStyle.js`：纯配置转换，适配横向、纵向、正负值、系列与单项样式；不改变原始数值、排名、坐标单位、轴范围、阈值、悬浮窗或参考线。
- `useChartStylePreferences.js`：按图表类型保存视觉偏好，存储不可用时仍可操作；重置删除偏好并恢复原图默认设置。
- `EChartBase.jsx`：通过可选的 `barStyleConfig` 接入。工具栏位于图表渲染节点外部；其他可视化目前不显示样式工具栏，后续可以扩展设置类型与适配函数。

## 接入约定

```jsx
<CartesianEChart
  option={option}
  barStyleConfig={{ key: 'unique-chart-type', scale: 100, suffix: '%' }}
/>
```

- `key` 是稳定的图表类型标识，不绑定数据集或运行；不同图表各自保存偏好。
- `scale / suffix` 只用于手动小数位的标签格式。例如比例数据用 `scale: 100, suffix: '%'`，已是百分比的数据只设置后缀。自动模式沿用原图 formatter。
- 数量图设置 `integerValues: true`，始终保留整数口径。
- 样式只针对当前的数值条形图 series，后续堆叠图或 dataset 编码图应先扩展适配策略再接入。

物种／KO 纵向丰度对比，门级／KO 组成，高丰度 KO 相对贡献，KO 差异效应量，MAG 丰度对比和 MAG 分类数量图。无数据时沿用原有空态；当前队列在默认 q < 0.05 下没有显著 KO，差异图的正负值样式通过有效候选夹具核查，没有回填非显著条目。

## 功能与行为

- 常驻圆角、数值、网格开关；更多设置提供细／标准／粗柱宽、自动／0–3 位小数、标签字号、图例、动画。
- 默认保留各图原有样式；手动圆角根据柱子方向和数值符号调整自由端，负效应标签保留左侧位置。
- 柱宽按分类槽位比例与原图最大宽度共同约束；标签开启碰撞隐藏，避免紧密图形的数值重叠。
- 隐藏网格仍保留零线、坐标刻度及 markLine；不改变全局色盲友好开关。
- 修改样式时保存当前缩放和图例系列选择。折线切换时隐藏条形图控件，切回后保留样式偏好。
- 工具栏通过共用上下文和 React Portal 放到最近的顶部 bar：物种／功能放在图表操作图标前，MAG 放在相应展开标题的导出按钮前。不依赖 DOM 查询搬移节点；独立使用且没有顶部宿主时才在图表前显示。
- 窄屏工具栏按顶部栏可用宽度换行，更多设置弹层右对齐；MAG 收起图表时同步隐藏工具栏，展开后保留偏好。

## 导出

沿用基于 ECharts 配置重新绘图的导出流程。导出包含用户设置后的图形样式；工具栏、设置弹层不在图表 SVG／Canvas 节点或 ECharts 配置中，所以不会进入 SVG／PNG，也不占用导出尺寸。
