# 2026-08-20 第二阶段开发收尾日志

## 记录目的

本日志汇总 AD-Meta 第二阶段围绕分析范围、科学展示规则、投影审计、查询性能和可视化交互完成的工作，并明确仍需在下一阶段实施的事项。

第二阶段的目标不是增加更多图表，而是让现有物种与 KO 分析具备稳定的分析范围、可追溯的展示规则和可复用的前后端结构。

## 本阶段完成内容

### 1. 分析范围与默认结果

- 建立全部样本、AD 组、NC 组、自定义子集和单样本等分析范围。
- 分析范围由稳定样本 ID 集合表达，后端以实际返回结果作为前端展示状态的依据。
- 不同可视化使用各自适用的范围与参数，不再把同一套筛选逻辑硬套到全部图表。
- 各图表保留独立的本地选择状态，切换图表时不会无提示地沿用上一张图的临时条件。
- 为常用默认范围建立预计算或可复用结果，首次进入图表时优先显示默认结果。

### 2. 完整结果、展示投影与审计信息分层

- 明确区分完整分析结果、当前图表数据和当前展示数据。
- 统一“查看当前图表数据”“查看当前展示数据”“查看筛选与合并明细”的折叠入口与表格骨架。
- 筛选与合并明细能够说明当前图表采用的排序、Top N、过滤、合并及未展示原因。
- 明细查询支持按物种或 KO、样本、处理结果和原因筛选，并提供排序和分页能力。
- 物种与 KO 使用各自领域术语，避免在用户界面中统一泛化为“特征”。

### 3. 图表专属科学策略

- PCA 明确记录参与计算的物种数、排序依据、标准化方式及解释方差。
- PCoA 引入最低检出率、最低相对丰度和闭合处理等过滤策略；排序坐标、距离矩阵、PERMANOVA 与 PERMDISP 使用一致的分析输入。
- 单组范围只用于探索性排序展示，不伪造组间检验结论。
- KO 与分类层级图的 Top N、长尾合并和层级压缩规则进入投影审计，合并不改变后端保留的完整结果。
- 当前 KO 组成仍按 KO 标识展示；未来按通路或功能类别聚合时，必须使用版本化注释映射，不能仅凭名称拼接。

### 4. 箱线图选择与计算链路

- 默认采用 Top 30，并使用一张连续箱线图和 `dataZoom` 浏览，不再把同一批物种拆成多页图表。
- 物种选择改为“待应用选择 + 应用选择 + 重置”，连续增删不会反复触发后端计算。
- 排名模式切换分析范围后重新计算范围内 Top N；自定义物种模式保留已选物种，只重新计算对应样本分布。
- 后端建立范围物种目录，复用物种名称、范围内平均丰度、排名、检出数和检出率，避免搜索时重复扫描完整矩阵。
- 箱线图只读取已选物种列并计算统计量，不再为少量展示物种重复计算全部物种。
- 支持原始丰度、`sqrt(丰度)` 与 `log10(丰度 + 1)` 三种展示变换；变换只用于箱线图展示，不改变物种选择、样本范围和后端原始结果。

### 5. 查询性能与派生结果复用

- 投影缓存身份包含数据修订、分析范围、图表参数和计算版本，避免不同范围或不同规则错误复用结果。
- 常用默认结果可预热；自定义范围按需计算并复用，重复请求不再无条件重算。
- 新结果计算期间保留上一版图表，并明确提示正在计算的范围，避免出现标题与图中样本不一致而无说明的状态。
- 已建立投影审计读模型，筛选与合并明细查询不再每次重新执行完整图表计算。

### 6. 完整结果服务与缓存生命周期

- 后端已提供基于不可变数据修订的完整结果分页查询能力。
- 后端已提供流式 CSV 导出能力，完整结果不经过 Top N 或图表投影裁剪。
- 派生投影区分默认结果和临时结果，并记录访问时间、过期时间与保留类别。
- 已具备临时投影清理和版本失效机制，避免自定义查询结果无限积累。

### 7. 前端骨架与可视化交互

- 图表卡片、标题区、参数区、状态摘要、图表主体和明细区采用稳定的结构分区。
- ECharts 图表在共享容器契约下响应尺寸变化，减少卡片、画布和标签区域不匹配的问题。
- 图表导出采用显式能力声明；导出时排除 `dataZoom`、工具箱和仅用于交互的辅助元素，避免把浏览控件写入科研图像。
- 导出入口保持轻量并与图例、状态摘要同层组织，不为不适合直接导出的图表硬加功能。
- 首页和分析工作区完成 AD-Meta 品牌标识替换，并保留低成本的悬停反馈。

## 验收结论

第二阶段要求的分析范围、投影规则、审计明细、默认结果、箱线图选择链路、查询缓存和前端图表骨架已经形成闭环。现有功能可进入持续使用与回归修复状态，本阶段不再新增结构性任务。

后续若发现图表计算错误、范围串用、缓存身份错误或展示裁剪，仍按缺陷处理，不因阶段结束而顺延。

## 纳入下一阶段实施

### 1. 独立的完整分析结果前端入口

后端分页查询和流式 CSV 服务已经完成，但当前尚未建设独立的完整结果浏览、筛选和下载页面。

顺延原因：纳入下一阶段实施。

下一阶段应直接复用现有完整结果服务，不从图表 payload 或投影缓存反向拼接完整数据。

### 2. 科学元数据 Manifest 接入

当前源文件尚未完整声明丰度单位、标准化方式、零值规则、注释数据库版本、上游参数、批次和协变量。系统现阶段只开放能够在未知尺度下安全解释的规则，并对上游标准化状态作明确提示。

顺延原因：纳入下一阶段实施。

下一阶段应由生信分析流程通过 AnalysisRun、Artifact 与 Manifest 契约交付这些元数据，再据此开放单位相关阈值、更多变换和论文级方法说明。

## 后续阶段边界

- 独立完整结果入口和科学元数据接入属于下一阶段工作，不作为第二阶段未完成故障。
- 论文级图像工作区、PCA / PCoA 解释性扩展表格、KO 功能类别映射和 MAG 分析继续按各自已有方案推进。
- 新增图表必须继续遵守“完整结果、展示投影、审计明细”三层数据边界，不得为浏览器性能直接删除或改写科学结果。
