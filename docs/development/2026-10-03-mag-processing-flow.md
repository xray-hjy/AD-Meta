# MAG 顶部处理流程

MAG 页面顶部的研究说明条替换为用户确认的连续流程组件；原研究用途及统计边界保留在组件底部“方法与来源”。

## 数据依据

- 9,133 个优化整合后的 bin 经 CheckM2 1.1.0 评估。
- 完整度 ≥50%、污染度 ≤10%：8,548 个通过，585 个排除。
- dRep 去冗余后得到 872 个代表；主聚类 ANI 90%、次级聚类 ANI 95%。聚类规则不替代实际成员—代表 ANI。
- 185 个样本，AD 122 / NC 63；666 个代表落在完整度 ≥90%、污染度 ≤5% 的参考范围。
- 依据已核查的服务器交付与 `docs/guides/server-transfer-audit.md`，不是重新执行上游程序。

`magProcessingProfiles.js` 将这些历史结果绑定到已核验 v3 manifest 的 SHA-256，且核对版本名及代表数量。未知包显示“待记录”，不继承旧批次数量。页面使用当前 overview 的 MAG 数量；样本筛选不会改变历史处理流程。

## 交互与样式

- 默认紧凑展示；点击步骤展开参数、来源及现有质量/去冗余/候选列表入口。
- 毛玻璃高亮圆角 4px；只高亮鼠标或键盘焦点所在步骤，无平移、上浮动画。
- 点击状态保留主题色标题和底线标记；悬浮其他步骤不替换点击详情。
- 节点高亮区域与完整底线共用下边缘，避免间隔与断线。
- 配色使用现有 workspace/theme tokens；窄屏纵向排列，支持键盘焦点及减少动画偏好。
- 流程位于图表之外，不进入图像导出。

此次仅展示来源及处理过程，不调整热图筛选、丰度值或统计结果。
