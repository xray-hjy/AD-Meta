## 原因和修复

- **frontend**：`npm audit --audit-level=high` 被依赖漏洞阻断。更新锁文件内兼容的补丁版本，将 Vitest 和 coverage-v8 同步升级为 5.0.3，运行环境要求明确为 Node.js 22.12 及以上。官方升级说明：[Vitest migration](https://vitest.dev/guide/migration/)。
- **mysql-integration**：测试使用了过时的 `payload.items`，真实投影响应为顶层 `items`。修正断言并核对两个 KO 特征和返回数量，业务接口未变。
- **browser-e2e**：首页页脚文字、工作区选中控件对比度不足；部分标题定位同时匹配页面二级标题与折叠区域三级标题。调整文字/主题颜色，将标题定位限定为二级标题。
- 新版 Vitest 默认清空用例之间的 mock 调用记录，暴露了参与样本测试提前断言的问题。改为等待当前折叠区域展开并调用 hook 后再断言。
- E2E 环境统一维护跨平台 Python 路径和系统临时目录，Windows 本地也能运行同一套流程。测试仍使用独立 SQLite 与临时存储，清理前校验目标目录边界。
