- 新增功能谱矩阵、功能总览、携带者分页、固定候选比较、专题基因集合、MAG/基因坐标证据、覆盖与丰度代理量、ARG/BGC 结果和系统发育轨道；图表沿用现有 ECharts 与 MAG 工作区样式。
- 使用不可变、内容哈希寻址的 SQLite 派生查询库保存大规模基因和注释明细，模块报告通过相对路径、大小及 SHA-256 绑定；无新增 MySQL schema migration。
- 更新 OpenAPI / 前端类型、storage manifest 中的 DRAM2 接入配置、数据导入说明、架构、API 与数据库文档，并提供 DRAM summary 审计记录。原始数据包由项目成员线下分发，不随代码提交。

## 数据和科学口径

- MAG 功能谱来自代表 MAG 的静态基因注释，不是样本表达量或群落 KO 丰度；注释未命中不表示生物学缺失。
- 功能代理量以样本为统计单位，由 CoverM MAG 百分比和功能基因计数计算，不解释为代谢通量或产物量。
- 群落 KO 仅按相同功能 ID 对照，未推断未经核验的 MAG→物种关系。ARG 候选和 BGC 结果不扩展为表型或临床结论。
- 统计仅作为 AD/NC 队列研究线索，不构成诊断、已验证生物标志物或因果结论。
