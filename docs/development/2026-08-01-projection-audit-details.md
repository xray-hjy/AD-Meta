# 2026-08-01 投影筛选与合并明细更新

## 背景

浏览器中的图表是完整分析结果的可视化投影。Top N、统计阈值、分类长尾聚合和桑基布局压缩不会删除数据库中的原始结果，但此前用户只能看到汇总数量，无法逐项追踪哪些特征被展示、合并或过滤。本次更新新增与当前投影严格绑定的审计明细，优先补齐科学可追溯性，不改变现有图表计算结果。

## 后端

- 新增投影审计请求与响应契约，并将读取接口拆分为元数据、筛选选项和分页行；旧组合接口仅用于兼容。
- 明细请求与当前 `projectionKey` 严格绑定；样本范围、Top N 或图表参数改变后，旧明细会返回 `409`，不会混用不同投影的解释。
- 普通投影 payload 不嵌入大明细表。审计行作为带来源修订、计算版本、结构版本和校验和的派生 Artifact 持久化；默认投影在部署预热阶段生成，缺失时由 API 幂等补建。
- 普通筛选、排序和分页由数据库索引执行，不再为每次翻页把所有审计行加载进 Python。
- 特征与样本筛选项采用延迟搜索接口，展开表格不会同步拉取数千个下拉选项。
- 差异热图、KO 检出率和 KO 差异特征计算器增加内部审计模式，普通调用的响应结构保持不变。
- OpenAPI 文档和前端生成类型已同步。

## 各图表明细

| 图表 | 主要明细 | 决策说明 |
| --- | --- | --- |
| 丰度对比 | 展示与未展示特征 | 按当前范围排序，区分 Top N 内外 |
| 门级组成 | `Other` 合并明细 | 展示每个门的真实占比和合并去向；占比列随 AD/NC、子集或单样本的当前序列动态生成 |
| 高丰度 KO 相对贡献 | Top N 展示选择明细 | 展示全部 KO 的共享排序、各序列相对贡献与累计覆盖率；未展示项保持独立可追溯，不合并为 `Other` |
| 丰度箱线图 | 计算特征选择 | 展示进入分布计算的特征和累计覆盖率 |
| PCA | 计算特征选择 | 展示进入 PCA 的特征、排序和覆盖率 |
| PCoA | 计算特征选择 | 展示进入 Bray-Curtis 距离计算的特征，不把它误写成视觉裁剪 |
| 差异热图 | 统计筛选明细 | 区分 q 值、效应阈值和展示上限 |
| KO 检出率热图 | 检出与展示筛选 | 区分未检出、检出但超出 Top N、已展示 |
| KO 差异特征 | 统计筛选明细 | 区分检出比例、FDR 和分组平衡展示上限 |
| 分类层级图 | 层级合并明细 | 原始物种可追溯到当前显示节点或长尾聚合节点 |
| 桑基图 | 层级合并与布局压缩 | 除分类合并外，列出布局压缩节点和合并数量 |

所有图表同时提供“样本范围”栏目，列出本次投影实际使用的样本、AD/NC 分组与来源研究。

## 前端

- `ChartFrame` 增加标准审计插槽；审计面板统一处理延迟加载、栏目切换、搜索、分页和错误状态。
- 栏目定义和明细内容按图表类型配置，没有把一个通用筛选表硬套到所有可视化。
- 面板摘要固定披露样本数、源特征数、当前展示数、合并数、未展示数和 Top N 的真实作用。
- 原“查看图表数据表”改名为“查看当前图表数据”，避免将 ECharts 当前绘制数据误认为完整分析结果。
- 明细表支持横向滚动和窄屏布局，不改变图表容器尺寸。
