# 群落分析结果选择项整理

## 对外展示

选择列表仅展示“AD/NC 群落分析”和“AD/NC 群落分析（旧版）”。前者为默认选择，包含 MetaPhlAn 4 物种及 DiTing KO/通路；后者对应既有旧结果。工具和结果口径仍在数据说明中展示，不在选择项中增加使用安排、追溯目的或版本推荐说明。

## 实现边界

- `backend/metadata/analysis_run_presentation.json` 独立配置展示名称、菜单可见性和默认项；不根据名称、日期或样本数在前端猜测版本。
- API 保留全部运行，提供 `selectorVisible`、`isDefault` 字段。过渡运行不出现在菜单中，但显式旧 URL 仍加载其原数据；名称可显示在选择器触发器中，不增加第三个可选项。
- 默认选择遵循显式 URL、登记默认项、首个可见项的顺序。显式选择旧版不会被默认项覆盖。
- 物种与功能在完整新版运行内部切换，不改变所选运行；未合并或覆盖历史修订。
- 展示配置不写回科研结果，不修改运行 key、artifact、修订、统计结果或外部证据快照。Manifest 中新版名称同步更新，不重新导入数据或重登记运行。

## 检查

后端隔离测试覆盖名称、默认项、未来未配置运行兼容、非法默认策略及历史运行不可变性。前端覆盖两项菜单、默认选择、显式历史链接、过渡链接和工作区导航；浏览器验收脚本为 `frontend/scripts/verify-analysis-versions.mjs`，截图输出至忽略目录 `frontend/.tmp/analysis-version-qa/`。
