# 群落数据集信息展示规则

日期：2026-10-02。状态：已实施。

## 产品展示范围

群落物种与群落 KO 工作区共用一套“数据说明”组件。入口位于侧栏数据概览，展开位置在当前图表标题下方。切换数据集时组件读取该分析产物绑定的 `datasetRevision`；切换图表时保持当前数据集信息。

主区使用统一字段展示数据类型、矩阵结构、样本数、特征数、分组构成、丰度尺度和标准化方法。“导入与版本信息”展开项展示源文件、样本编号筛选、排除数量、分组映射、缺失值与重复特征处理、版本编号和 SHA-256。缺少字段时显示“未提供”或不展示该项。

已核实的公开来源另以结构化字段展示 NGDC GSA、BioProject 和原始测序数据关联论文。当前版本的样本编号集合与分组构成须同时匹配 `backend/metadata/verified_cohorts.json` 中的已核实队列，才会显示这些链接；未匹配时不展示来源卡片。该登记按队列维护，物种与 KO 不分别编写文案。

数据类型仅依据受控的 `featureKind` 和 `featureLabel` 显示。图表旁的简短口径提示读取当前分析产物的丰度尺度与标准化方法，不推测具体数值单位。

## 数据来源

后端 `/api/datasets/{slug}/revisions/{revision_key}/description` 读取指定已发布 revision 的数据库记录和该 revision 的导入校验报告。样本分组优先从该 revision 的样本索引统计；特征数优先从该 revision 的校验报告读取。源文件名只在请求当前 revision 时从数据集记录读取，避免旧版本误用新文件名。

页面不维护按数据集编写的说明文案。新增同类型数据集，只要按现有导入流程登记数据和校验报告，即可使用相同组件；新增公开队列须先核实并登记其结构化来源及样本集合指纹。更广泛的数据类型需要先定义对应的受控类型标签与字段语义。

## 内容边界

已完成的 NGDC 样本核对、原始 reads 的项目与论文关联可以展示。论文作为原始测序数据关联论文，不代表当前物种或 KO 矩阵直接由论文方法生成。团队筛选原因、上游脚本状态以及服务器文件差异仍属内部核查事项，产品页面不展示讨论中的推断或待询问事项。
