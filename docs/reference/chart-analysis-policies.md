# 图表分析策略与投影契约

## 目的

AD-Meta 的图表共享样本范围、参数校验、缓存和响应元数据等基础设施，但不共享一套笼统的统计方法。每种图表必须声明自己的分析目的、可用范围、最低样本要求、参数含义和计算模块，后端是这些规则的权威实现，前端只负责提供与之对应的操作界面。

## 数据边界

1. **完整分析结果**：数据库与后端保存的真实分析结果，不因浏览器性能而删除。
2. **可视化投影**：后端根据当前样本范围和图表策略生成的紧凑 payload，可包含特征选择、Top N 展示或长尾聚合。
3. **投影审计明细**：与当前 `projectionKey` 严格绑定的分页决策记录，回答每个样本或特征为何被展示、合并、过滤或排除。
4. **完整结果与论文级导出**：从后端完整结果生成，不依赖浏览器中当前绘制的节点数量，也不把交互图截图等同于论文图。

响应中的 `analysisFamily` 说明分析类别，`topNRole` 说明 Top N 的真实作用：

- `feature_selection`：Top N 在计算前选择特征，会改变排序或分布计算输入。
- `display_cap`：统计检验先作用于全部合格特征，Top N 只限制浏览器展示数量。
- `aggregation_limit`：超过上限的组成项聚合为 Other，保留总量关系。
- `not_applicable`：该投影不使用通用 Top N。

## 当前图表策略

| 图表 | 分析范围 | 专属策略 | Top N 含义 |
| --- | --- | --- | --- |
| 丰度对比 | 全部、单组、子集、单样本 | 描述所选范围的均值或单样本丰度 | 展示排序上限 |
| 门级组成 | 全部、单组、子集、单样本 | 按门水平汇总组成占比，长尾聚合后总量保持一致 | 聚合上限 |
| 高丰度 KO 相对贡献 | 全部、单组、子集、单样本 | 样本内总和归一化后计算组均值；共享排名展示 Top N，不生成 `Other` | 展示排序上限 |
| 分类层级图 | 全部、单组、子集、单样本 | 统一分类树，按各图专属投影生成旭日图、矩形树图、桑基图和放射树图 | 不使用通用 Top N |
| 丰度箱线图 | 至少 2 个样本；允许单组 | 描述所选特征的四分位数、须和离群点 | 参与分布展示的特征选择 |
| 差异热图 | AD、NC 均至少 3 个样本 | 对全部特征做 Mann-Whitney U 与 BH-FDR；再按 q 值及绝对 log2FC 筛选和聚类 | 合格候选的展示上限 |
| KO 检出率热图 | AD、NC 均至少 3 个样本 | 当前仅使用与单位无关的 `abundance > 0` 检出规则，按两组检出率差排序 | 已检出 KO 的展示上限 |
| KO 差异特征 | AD、NC 均至少 3 个样本 | 检出比例预筛、Mann-Whitney U、BH-FDR 和 rank-biserial 效应量 | 显著候选的平衡展示上限 |
| PCA | 至少 3 个样本；允许单组 | 按样本闭合后的平均相对丰度选特征，所选子组成再次闭合、乘法零值替换并 CLR 后做 PCA；椭圆表示组内 95% 数据分布，不是均值置信区间 | 参与 PCA 计算的特征数 |
| PCoA | 至少 3 个样本；允许单组 | 全矩阵按样本闭合后执行无标签的相对丰度/检出率过滤，再闭合并计算 Bray-Curtis 与经典 PCoA；两组均不少于 3 个样本时计算探索性 PERMANOVA 与使用正/负轴校正的 PERMDISP | 不使用 Top N；使用可审计过滤预设 |

## 参数与界面规则

- 统计阈值使用经过审核的离散预设，不提供看似灵活但缺乏解释的任意输入框。
- 前端必须区分“分析筛选”“计算参数”和“展示设置”，切换图表时删除不属于该图的旧参数。
- 自定义子集在提交前显示样本总数及 AD/NC 数量；后端再次执行同样的权威校验。
- 单组 PCA/PCoA 只作探索性排序，不报告组间推断结论。
- PCoA 默认使用“标准”预设：单样本相对丰度达到 `0.01%` 视为检出，特征检出率至少 `10%`。另提供不过滤、宽松（`0.001%`、`5%`）和稳健（`0.05%`、`20%`）预设。所有预设都不读取 AD/NC 标签。
- PCoA 的坐标、PERMANOVA 与 PERMDISP 必须来自同一份 Bray-Curtis 距离矩阵，并返回距离矩阵指纹。过滤前后的样本内总和闭合、零总量样本排除及保留丰度质量必须进入响应元数据和审计明细。
- PERMDISP 必须披露负轴校正后的截断距离数量；若组内离散距离或有效置换退化，不返回可解释的 p 值，界面明确标记为“不可解释”。
- 当前 Manifest 尚未提供来源研究、协变量和可信的上游丰度尺度，因此 PCoA 组间检验只能标记为“探索性、未分层、未校正”。这些信息补齐前，不得把结果描述为正式的批次校正推断。
- 当前来源文件未声明丰度尺度和标准化方法，界面必须显示“上游标准化方式待确认”。在 Manifest 明确这些语义前，不开放依赖具体单位的检出阈值。
- 浏览器加载状态应说明正在执行当前图表的专属计算策略，不暗示所有图使用同一算法。

## 筛选与合并明细契约

前端所有后端投影图共用“查看筛选与合并明细”入口，但共用的只是查询、分页、搜索和表格外壳。栏目与行数据由图表策略决定，不能用一张通用表猜测不同图表的科学语义。

- 明细通过 `POST /api/analysis-runs/{run}/artifacts/{artifact}/projection-audits/{kind}` 延迟加载；普通投影响应保持紧凑。
- 请求必须携带当前图表的 `projectionKey`、样本范围、Top N 和专属参数。后端重新生成投影身份，身份不一致时返回 `409`，禁止展示过期明细。
- 丰度对比：列出参与排序的全部特征、排名，以及是否位于当前 Top N。
- 门级组成：列出真实门级类别、AD/NC 或当前序列占比、是否展示，以及合并到 `Other` 的具体类别；占比列必须根据当前范围的实际序列动态生成，单样本不能沿用 AD/NC 空列。
- 高丰度 KO 相对贡献：列出全部 KO 的共享排名、各序列相对贡献、累计覆盖率及是否进入 Top N；未展示 KO 不合并，必须可分页追溯。
- PCA：列出参与计算的特征、按样本闭合后的平均相对丰度及未进入计算的特征；该排序不使用原始总丰度或测序深度。
- 箱线图：列出参与计算的特征、总丰度、累计覆盖率及未进入计算的特征。
- PCoA：逐特征列出检出样本数、检出率、平均/最大相对丰度、保留状态与排除原因；同时披露预设阈值、过滤前后特征数、零总量样本和保留丰度质量。PCoA 不使用 Top N。
- 差异热图/KO 差异特征：列出完整统计候选及 p、q、效应量、log2FC、检出比例等适用字段，并区分未过阈值与通过统计筛选但受展示上限限制。
- KO 检出率热图：列出所有 KO 的 AD/NC 检出率、检出率差、是否未检出或受展示上限限制。
- 分类层级图：把原始物种映射到当前展示路径，明确长尾合并目的节点；桑基图另提供布局压缩节点及其合并数量。
- 所有图表都提供当前样本范围栏目，列出样本、分组和来源研究，防止图表范围与明细范围脱节。

“查看当前图表数据”只表示 ECharts 当前绘制的数据；“查看当前展示数据”表示当前投影在界面上的整理表。二者都不是完整分析结果。完整结果分页与 CSV 下载已由独立服务提供，接口和稀疏矩阵语义见 [完整分析结果与投影生命周期](./complete-results-and-projection-lifecycle.md)；论文级导出仍应走后续独立服务。

PCA 载荷、PCoA 质心距离与特征值诊断在展开后按页渲染，避免大样本队列一次创建无界表格 DOM；分页只影响浏览器呈现，不删减后端解释资源。

## 新增图表检查清单

新增可视化时需要同时完成：

1. 在后端 `projection_policy.py` 声明分析类别、范围、样本下限、Top N 角色和参数边界。
2. 在独立计算模块中实现该图的转换或统计方法，不把科学计算写进 React 组件。
3. 返回筛选前数量、合格数量、展示数量、合并数量和数据语义，并实现对应的投影审计栏目。
4. 在前端 `chartRegistry.js` 提供与后端一致的控件、说明和适用范围。
5. 为合法范围、非法范围、参数默认值、参数越界和元数据披露添加测试。
6. 明确交互图与未来论文级导出的差异；论文导出不得直接截图当前浏览器投影冒充完整分析结果。
