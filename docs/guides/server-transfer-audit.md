## 当前物种矩阵还存在来源差异

当前 Excel 原表 9,820 个特征列，平台合并一个重复列后使用 9,819。服务器 MPA 表有 13,710 个物种；目前按末端物种名称统一空格/下划线后，7,917 个 Excel 列能唯一对应，1,903 个没有对应。

这是按名称进行的初步比较，未证明全部物种的 TaxID 身份；不能据此猜测批次差异原因，也不能把服务器表直接当成当前 Excel 的原始生成结果。应取得 Excel 的实际生成说明和脚本，确认来源批次、数据库及转换/过滤/拼接规则。

species_taxonomy_crosswalk 的 Reads 观察标签来自本批服务器 Bracken 集合。当前 Excel 来源未对齐时，不能将该观察范围自动当成 Excel 的特征范围；需要绑定明确的矩阵/运行版本。
