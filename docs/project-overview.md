# AD-Meta 项目背景与边界

## 项目定位

AD-Meta 是一个面向阿尔茨海默病（Alzheimer's Disease, AD）脑肠轴研究的肠道宏基因组研发辅助工具。系统以宏基因组生物信息分析结果为数据基础，当前支持群落物种组成和 KO 功能层面的分析与可视化，并面向 MAG（Metagenome-Assembled Genomes，宏基因组组装基因组）的分类、丰度、功能及特殊功能解析进行扩展。

工具采用“后端预计算 + 前端渲染”的前后端分离架构：后端从结构化分析数据生成统计结果和图表 payload，前端通过 API 读取缓存结果并使用 ECharts 等可视化库完成交互展示。

## 数据来源

项目数据来源于公开数据库中的 AD 相关肠道宏基因组原始测序样本。独立的生物信息分析流程负责把原始测序数据转换为本工具可导入的结构化分析结果。

当前分析流程概况：

1. 获取公开 FASTQ 原始测序数据。
2. 进行质量控制与清洗。
3. 对 Clean Reads 进行 Reads 水平物种分类和丰度校正，生成 Sample x Species 矩阵。
4. 使用 MEGAHIT 等工具完成序列组装，并基于组装结果开展基因预测、功能注释和 Reads 定量，生成 Sample x KO 矩阵。
5. 规划通过覆盖度计算、分箱、质量评价和去冗余获得 Final MAGs 及其下游分析结果。

## 当前进度

已经完成并接入工具的主要分析数据：

- AD/NC 样本分组信息。
- 物种分类与物种丰度表。
- KO 功能丰度表。

尚未完成或尚未纳入当前数据版本的流程：

- 基因组分箱（如 MetaBAT2、CONCOCT）。
- MAG 质量评估和去冗余（如 CheckM2、dRep）。
- MAG 覆盖度计算、系统发育重建、功能注释和生物合成基因簇分析。

因此，当前工具中的群落物种和 KO 分析不应被描述为已经完成的 MAG 分析能力。

## 仓库边界

生物信息分析流程与 AD-Meta 分开开发，相关 Shell 脚本、工作流配置和大型中间文件不在本仓库中。

本仓库负责：

- 导入结构化物种丰度表和 KO 丰度表。
- 管理导入批次元数据、标准化分析表和图表缓存。
- 预计算统计分析及可视化专用 payload。
- 提供只读 API。
- 提供 React 分析工作区和可视化页面。

本仓库不负责：

- 下载和处理 FASTQ。
- 运行质控、组装、分箱或 MAG 分析工具。
- 保存完整生信流程的大型中间产物。

未来接入 MAG 分析结果时，应通过新的结构化导入契约、数据库表和图表投影扩展工具，不应把生信工具命令直接嵌入现有前端或图表 API。
