# AD-Meta 项目背景与边界

## 项目定位

AD-Meta 是一个面向阿尔茨海默病（Alzheimer's Disease, AD）脑肠轴研究的肠道宏基因组研发辅助工具。系统以宏基因组生物信息分析结果为数据基础，当前支持群落物种组成、KO 功能以及 MAG（Metagenome-Assembled Genomes，宏基因组组装基因组）丰度、GTDB 分类和 CheckM2 质量结果的分析与可视化；MAG 功能注释和独立跨队列复现仍按数据就绪度逐步接入。

工具采用“后端预计算 + 前端渲染”的前后端分离架构：后端从结构化分析数据生成统计结果和图表 payload，前端通过 API 读取缓存结果并使用 ECharts 等可视化库完成交互展示。

## 数据来源

项目数据来源于公开数据库中的 AD 相关肠道宏基因组原始测序样本。独立的生物信息分析流程负责把原始测序数据转换为本工具可导入的结构化分析结果。

当前 185 个 CRR 样本的官方项目身份、AD/NC 子队列构成、编号含义、论文和数据下载入口见[《生物信息流程与分析数据接入》](reference/bioinformatics-analysis-data.md#当前-crr-队列的官方来源)。

当前分析流程概况：

1. 获取公开 FASTQ 原始测序数据。
2. 进行质量控制与清洗。
3. 对 Clean Reads 进行 Reads 水平物种分类和丰度校正，生成 Sample x Species 矩阵。
4. 使用 MEGAHIT 等工具完成序列组装，并基于组装结果开展基因预测、功能注释和 Reads 定量，生成 Sample x KO 矩阵。
5. 上游 MAG 流程交付代表 MAG 目录、Sample x MAG 丰度矩阵、GTDB 分类和 CheckM2 质量结果；本仓库读取版本化结构化结果，不在运行时执行分箱、质量评价或分类工具。

## 当前进度

已经完成并接入工具的主要分析数据：

- AD/NC 样本分组信息。
- 物种分类与物种丰度表。
- KO 功能丰度表。
- 185 个 CRR 样本的 Sample x MAG 丰度矩阵及 872 个代表 MAG 的基本信息。
- 872 个代表 MAG 的 GTDB 分类和 CheckM2 质量结果。
- MAG 样本映射、数据指纹、来源清单和已确认的 CoverM 技术参数。

尚未完成或尚未纳入当前数据版本的流程：

- MAG x KO 功能归属以及 ARG、CAZyme、BGC 等特殊功能注释。
- 可作为稳定数据产品读取的 MAG 系统发育树。
- dRep 跨队列语义、覆盖深度指标和独立跨队列复现结果。
- GTDB-Tk 与 GTDB reference release 的完整版本信息。

因此，当前 MAG 模块只应描述为已接入丰度、分类、质量和技术质控；群落层面的 KO 结果不能表述为具体 MAG 的功能归属，未接入能力不得展示模拟结果。

## 仓库边界

生物信息分析流程与 AD-Meta 分开开发，相关 Shell 脚本、工作流配置和大型中间文件不在本仓库中。

本仓库负责：

- 导入结构化物种丰度表和 KO 丰度表。
- 读取和校验版本化的外部 MAG 数据包。
- 管理导入批次元数据、标准化分析表和图表缓存。
- 预计算统计分析及可视化专用 payload。
- 提供只读 API。
- 提供 React 分析工作区和可视化页面。

本仓库不负责：

- 下载和处理 FASTQ。
- 运行质控、组装、分箱或 MAG 分析工具。
- 保存完整生信流程的大型中间产物。

后续 MAG 功能、系统发育和跨队列结果仍应通过版本化结构化契约扩展，不应把生信工具命令直接嵌入现有前端或图表 API。
