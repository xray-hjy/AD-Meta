# AD-Meta 项目背景与边界

## 项目定位

AD-Meta 是面向阿尔茨海默病（AD）与肠道菌群宏基因组数据的可视化分析平台，用于展示和比较 AD 组与正常对照（NC）组的物种组成、物种丰度、KO 功能、多样性和分类层级关系。

平台采用“后端预计算 + 前端渲染”的前后端分离架构：后端从结构化丰度表生成统计结果和图表 payload，前端通过 API 读取缓存结果并使用 ECharts 等可视化库完成交互展示。

## 数据来源

项目数据来源于公开数据库中的 AD 相关肠道宏基因组原始测序样本。独立的生物信息分析流程负责把原始测序数据转换为本平台可导入的结构化结果。

当前分析流程概况：

1. 获取公开 FASTQ 原始测序数据。
2. 进行质量控制与清洗。
3. 使用 MEGAHIT 等工具完成序列组装，生成 contigs。
4. 基于组装结果进行基因预测和注释。
5. 生成物种丰度表和 KO 功能丰度表，作为 AD-Meta 的主要输入。

## 当前进度

已经完成并可供平台使用的主要产物：

- AD/NC 样本分组信息。
- 物种分类与物种丰度表。
- KO 功能丰度表。

尚未完成或尚未纳入当前数据版本的流程：

- 基因组分箱（如 MetaBAT2、CONCOCT）。
- MAG 质量评估和去冗余（如 CheckM2、dRep）。
- MAG 覆盖度计算、系统发育重建、功能注释和生物合成基因簇分析。

因此，当前平台中的物种和 KO 可视化不应被描述为 MAG 分析结果。

## 仓库边界

生物信息分析流程与 AD-Meta 平台分开开发，相关 Shell 脚本、工作流配置和大型中间文件不在本仓库中。

本仓库负责：

- 导入结构化物种丰度表和 KO 丰度表。
- 管理数据集元数据、标准化表和图表缓存。
- 预计算统计分析及可视化专用 payload。
- 提供只读 API。
- 提供 React 分析工作区和可视化页面。

本仓库不负责：

- 下载和处理 FASTQ。
- 运行质控、组装、分箱或 MAG 分析工具。
- 保存完整生信流程的大型中间产物。

未来接入 MAG 数据时，应通过新的结构化导入契约、数据库表和图表 projection 扩展平台，不应把生信工具命令直接嵌入现有前端或图表 API。
