# 已存在的缺项与验证边界

## 本包保留的现状

1. 当前发布数据集的 19 份图表缓存均存在且与 MySQL 固定的 SHA-256 相符。
   原机数据库还引用 42 份旧修订缓存，但对应文件在原机已经不存在。
   本包完整保存这些数据库记录，并在 `database/source-state.json` 的 `historical_chart_gaps` 列出路径与预期哈希；
   不生成替代缓存、不删除历史记录，也不声称已经恢复这些旧文件。当前发布页面的缓存校验不受该历史缺失影响。
2. MAG 原始归档已知缺少三份历史 dRep 输入：
   `dRep/dRep_input/genomeInfo.csv`、`dRep/dRep_input/quality_filtered_MAGs.list`、`dRep/dRep_input/quality_filtered_MAGs.tsv`。
   它们属于既有来源/关系证据缺项；保留应用发布状态与缺失标记，不把缺失内容伪造为零。
3. DRAM2 原始 distill 与基因计数之间的差异仍待上游解释；保留原表和审计记录。
   当前功能查询使用固定的基因一致计数库，不把该部署当作新的科学验证或完整通路结论。
4. GMrepo 与主队列是不同的数据来源与统计范围，沿用原有身份审查、样本分母和来源限制，不合并改写。

## 已做与待做

- 新前端已在本机使用 Node 24 构建；生产文件已提供。
- MySQL 逻辑备份包含 39 张表，经过 gzip 全量读回；备份前后逐表行数与发布修订一致。
- 本机独立数据库恢复、已打包代码的接口验证结果以 `database/local-restore-test.json` 为准。
- 目标 OpenCloudOS 上的软件安装、MySQL 跨版本兼容、Linux R 依赖、目标站点、HTTPS、外网访问尚未由本机代理执行。
- 源 MySQL 为 9.5.0；不能把本机同版本恢复成功等同于 MySQL 8.x 已验证。目标端先空库结构预检，再完整恢复并比对。
- 运行依赖需要服务器联网安装；本包包含应用和数据，不包含全部 Linux 系统软件及 R 编译产物。
- 完整正式统计能力须 R 模型 smoke test 和 worker 健康/ready 校验都通过。仅关闭 worker 校验使 ready 成功不等于统计服务已上线。

源数据库与原文件没有因打包而重算或改写。数据库备份、索引哈希和发布修订是验收依据。
